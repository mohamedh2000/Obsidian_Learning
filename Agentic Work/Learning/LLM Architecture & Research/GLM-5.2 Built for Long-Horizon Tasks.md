# GLM-5.2 Built for Long-Horizon Tasks

> Z.ai presents GLM-5.2 as a flagship open model for long-horizon work, with 1M-token context, stronger agentic coding, and effort-level control.

## Key Points

- GLM-5.2 targets long-horizon tasks where models must keep quality across long, messy coding-agent trajectories rather than merely accepting long prompts.
- The model extends maximum context to 1M tokens and emphasizes long-context inference scalability, KV-cache pressure, and throughput at larger context lengths.
- Z.ai claims strong open-model performance on long-horizon coding and agentic benchmarks including FrontierSWE, PostTrainBench, SWE-Marathon, Terminal-Bench, and SWE-bench Pro.
- The release introduces effort-level control so users can trade off reasoning depth, speed, and cost for different coding and reasoning workloads.
