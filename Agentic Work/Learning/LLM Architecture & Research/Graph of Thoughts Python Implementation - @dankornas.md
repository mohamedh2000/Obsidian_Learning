## Key Points

- Official Python implementation of the "Graph of Thoughts" paper for structured LLM reasoning experiments.
- Lets builders define flexible operation graphs that can resemble Graph of Thoughts, Chain-of-Thought, or Tree-of-Thought workflows.
- Includes examples, PyPI installation, and inspectable output graphs with operations, thoughts, scores, token use, and cost.
