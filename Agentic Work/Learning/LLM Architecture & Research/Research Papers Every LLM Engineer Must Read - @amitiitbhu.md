## Key Points

- **Attention Is All You Need** — the Transformer architecture, self-attention replacing recurrence
- **BERT** — masked language modeling and bidirectional context
- **GPT-3: Language Models are Few-Shot Learners** — 175B-parameter decoder-only model and in-context learning
- **Scaling Laws for Neural Language Models** — predictable loss decrease with compute, data, and parameters
- **Chinchilla** — compute-optimal training: ~20 tokens per parameter
- **InstructGPT** — RLHF with supervised fine-tuning, reward modeling, and PPO
- **Chain-of-Thought Prompting** — step-by-step reasoning improves math and logic
- **RAG (Retrieval-Augmented Generation)** — retriever + generator for factual answers
- **LoRA** — 10,000x fewer trainable parameters via rank-decomposition matrices
