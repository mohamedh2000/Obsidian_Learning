## Key Points

- The article distinguishes visibility studies based on outputs from direct inspection of raw network traffic.
- ChatGPT source behavior includes fanout queries, where one user question can turn into multiple searches.
- Fetched, cited, and mentioned sources are separate signals and should not be treated as equivalent.
- Some queries never reach the web, so optimization depends on understanding when search is invoked.
