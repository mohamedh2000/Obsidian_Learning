# Introducing Inkling — Thinking Machines' Open-Weights Model

> Thinking Machines Lab releases Inkling, a 975B-parameter open-weights MoE model (41B active) with native multimodality, controllable reasoning effort, and fine-tuning support via Tinker.

## Key Points

- Mixture-of-Experts transformer: 975B total / 41B active parameters, up to 1M token context, pretrained on 45T tokens across text, images, audio, and video.
- Natively multimodal (text, vision, audio) with "controllable thinking effort" — reaches competitive results using roughly one-third the tokens of rivals.
- Strong agentic capabilities: tool use, web browsing, and code generation; ranks competitively on Design Arena's web-dev leaderboard.
- Optimized for broad customization rather than single benchmarks — fine-tunable on Tinker (famously self-tuned into a "lipogram model" avoiding the letter 'e').
- Training emphasized calibration, factuality/claim-checking, and robust refusals, with external safety testing across dangerous-capability and human-AI threat domains.
