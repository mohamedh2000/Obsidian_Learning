## Key Points
- Theo runs a chat application explicitly designed for non-coders, providing real-world evaluation data outside the typical coding benchmark paradigm
- Gemini 2.5 Flash was used as the default model for a full year, giving substantial production data to draw from
- Assessment: Gemini Flash performs "awful" and is "a generation behind" for non-code conversational use cases
- Kimi K2 (from Moonshot AI) caused user satisfaction to "skyrocket" after replacing Gemini Flash as the default

### Why This Matters
Most LLM benchmarks focus on coding, math, and reasoning tasks where frontier models excel. Theo's experience highlights a gap: models optimized for technical tasks may underperform on general conversational quality, emotional intelligence, and non-technical explanations. Kimi K2 appears to occupy a different part of the quality-cost tradeoff space that better serves non-technical users.

### Implications for Model Selection
If building consumer-facing chat products for non-technical audiences, benchmark scores on HumanEval or MATH may be misleading indicators of actual user satisfaction. Production A/B testing with satisfaction metrics may reveal that models like Kimi K2 outperform supposedly superior models in real usage.
