## Key Points

- Frames MSA as a native long-memory architecture where sparse attention replaces both RAG-style retrieval and heavily compressed long-context memory schemes.
- Highlights document-wise RoPE for keeping document boundaries and ordering intact, plus Memory Interleaving for multi-hop reasoning across scattered memory fragments.
- Points to the open-source `EverMind-AI/MSA` repo and claims scaling from 16K to 100M tokens with less than 9% accuracy drop while a 4B model beats top-tier RAG systems on long-context benchmarks.
