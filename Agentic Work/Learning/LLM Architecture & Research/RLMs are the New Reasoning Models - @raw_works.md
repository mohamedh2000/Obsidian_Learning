# RLMs Are The New Reasoning Models

> Recursive Language Models collapse reasoning and tool use into a single inference abstraction: the model treats its own prompt as an environment it can inspect, slice, and recursively query.

## Key Points

- RLMs are the direct marriage of reasoning and tool use — treating context itself as the object of computation
- A Recursive Language Model treats its input prompt as an environment rather than a fixed string, with a REPL allowing inspection and slicing
- RLMs can process inputs up to two orders of magnitude beyond the underlying model's context window
- Reasoning is about allocating inference-time compute; tool use is about calling external functions and handling schemas/retries
- Key papers: Zhang, Kraska, Khattab on RLMs; Toolformer made the distinction between reasoning and tool use clear
- RLMs outperform vanilla frontier LLMs and common long-context scaffolds across four long-context tasks
