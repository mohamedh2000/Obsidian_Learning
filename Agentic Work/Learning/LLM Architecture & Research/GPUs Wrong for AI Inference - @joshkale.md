## Key Points

- GPUs were designed for training but inference is memory-bound and sequential -- a fundamentally different problem
- Every trend (MoE, reasoning, long context, multimodal) makes the memory bottleneck worse
- The next $100B+ hardware cycle will be won by whoever solves the memory wall first
