## Key Points

- Start with fundamentals: Python, Git, Bash, testing, how software is built.
- Work with LLM APIs: prompts, structured outputs, function calling, streaming, caching, context management.
- Make LLMs smarter: prompt engineering, RAG, embeddings, fine-tuning, external knowledge access.
- Master retrieval: vector databases, indexing, hybrid search, reranking, retrieval strategies — then combine into production RAG pipelines.
- Build agents (memory, tools, multi-agent workflows, planning, human-in-the-loop), learn AI infrastructure (containers, CI/CD, model routing, Kubernetes, inference), master evaluation (tracing, observability, eval datasets, LLM-as-a-judge), and AI security (guardrails, sandboxing, prompt-injection protection).
- Advanced track: voice/vision/coding agents, MCP servers, agent swarms, self-improving systems.
