> Transformer Explainer is an interactive visualization that shows how transformer models process tokens, attention, probabilities, and generation settings.

## Key Points

- The tool explains tokenization, embeddings, transformer blocks, attention, MLP layers, output probabilities, and generation controls.
- It uses a live GPT-2 small model in the browser, derived from nanoGPT and converted to ONNX Runtime.
- Interactive controls let users inspect attention maps, temperature, top-k, and top-p behavior.
- The page includes an article-style walkthrough and links to a paper, video, and GitHub repository.
