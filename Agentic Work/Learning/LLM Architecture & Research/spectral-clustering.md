# Spectral Clustering

> Spectral clustering groups data by studying the eigenstructure of a similarity graph, which makes it useful when cluster boundaries are non-convex or graph-shaped.

Research topic around a clustering technique that builds a similarity graph, studies the graph Laplacian, and uses its eigenvectors to reveal structure before applying simpler grouping methods.

## Key Points

- Instead of clustering directly in the original feature space, spectral clustering transforms the problem through a similarity matrix and graph representation.
- It is especially useful when clusters are not spherical or linearly separable, where k-means-style assumptions break down.
- This matters for code and knowledge systems because graph-based structure can capture relationships that plain geometric distance misses.
