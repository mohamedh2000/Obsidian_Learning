> Skills are reusable capabilities for AI agents. Install them with a single command to enhance your agents with access to procedural knowledge. 90K+ skills across 20+ agent platforms.

**Topics:** [[Developer Tools]], [[AI Agents]], [[Claude Code & Anthropic]]

## Key Points
- **What it is**: Marketplace/directory for discovering and installing reusable AI agent skills — think npm for agent capabilities
- **Installation**: Single command via `npx skills add <owner/repo>` or `npx skills add <owner/repo> --skill <skill-name>`
- **Scale**: 90,000+ skills available, most-installed skill ("find-skills") has 1.2M installations
- **Platform support**: Works with Claude Code, Cline, Cursor, GitHub Copilot, Gemini, and 20+ other agent frameworks

### How Skills Work
Skills inject procedural knowledge into AI agents — instructions, patterns, and domain expertise that improve agent behavior for specific tasks. Unlike traditional packages that add code, skills add knowledge that agents can apply contextually.
