# Context+ - Semantic Intelligence for Large-Scale Engineering

> Context+ turns a large codebase into a searchable graph by combining RAG, Tree-sitter ASTs, spectral clustering, and Obsidian-style links.

Transforms large codebases into searchable, hierarchical graphs by combining RAG, Tree-sitter AST parsing, and spectral clustering. Provides semantic code search, blast radius analysis, and symbol navigation with "99% accuracy" while minimizing context window bloat. You're already using this in your Visibl project.

## Key Points

- The product is presented as an MCP server for high-precision code intelligence in large engineering codebases rather than a generic chat layer over files.
- Feature areas include semantic search, file skeletons, identifier search, blast radius, static analysis, and code-op functions like propose commit and restore points.
- It also exposes memory operations, which suggests it is meant to be part retrieval layer and part persistent engineering workspace for agents.
