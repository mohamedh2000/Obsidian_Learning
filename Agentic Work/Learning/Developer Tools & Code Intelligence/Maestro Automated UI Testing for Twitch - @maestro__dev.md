### Why Maestro
Traditional mobile UI testing tools (Appium, Espresso, XCTest) require complex setup and brittle selectors. Maestro uses:
- Simple YAML-based test definitions
- Automatic element detection
- Built-in retry and wait logic
- Cross-platform (iOS + Android) from single test files

### Use Cases
- Regression testing for mobile apps
- Smoke tests in CI/CD pipelines
- Visual QA automation
- User journey validation
