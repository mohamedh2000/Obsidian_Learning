> VibeMotion-1 is an open-source pre-alpha video editing tool that imports Figma frames with all layers intact, animates layers via prompt, and uses LTX-2.3 AI model locally for image-to-video generation — all on a classical editing timeline.

## Key Points
- **Figma-to-Video bridge** — Import Figma frames with layer structure preserved, not just flattened images
- **Prompt-based animation** — Animate individual layers using natural language prompts
- **LTX-2.3 integration** — Local, open-source AI model for image-to-video generation (no cloud dependency)
- **Classical timeline UI** — Familiar editing interface rather than novel paradigm
- **Pre-alpha status** — Early release, expect rough edges but also opportunity to shape direction

### Why This Matters
Bridges the gap between static design tools (Figma) and video output without requiring After Effects expertise. The local AI approach (LTX-2.3) means no API costs and no data leaving your machine. Open source enables customization for specific workflows — could be integrated into design-to-marketing pipelines.
