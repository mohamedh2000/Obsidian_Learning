## Key Points
- **Problem solved**: ASCII diagrams in Claude Code are hard to read and edit; Flowy provides a visual alternative with bidirectional sync
- **Architecture**: Claude outputs JSON → Flowy renders interactive flowcharts/mockups → user edits visually → Claude sees changes back
- **Demo context**: Showcased on Every's Vibe Code Camp livestream, indicating production-readiness and community interest
- **Access model**: Community-driven early access via "comment flowy" on the post — suggests high demand tracking before public release

### How It Works
The tool bridges the gap between text-based AI outputs and visual design workflows. Instead of Claude producing raw ASCII art that's difficult to modify, it generates structured JSON that Flowy interprets and renders as editable diagrams. The bidirectional sync means user modifications in the visual editor propagate back to Claude's context, enabling iterative design collaboration without copy-paste friction.
