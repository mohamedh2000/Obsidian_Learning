## Key Points

- Official MCP server from the draw.io team (jgraph organization)
- Four integration approaches: MCP App Server (renders inline in chat), MCP Tool Server (opens in draw.io editor), Skill + CLI (generates native files), and Project Instructions (no installation needed)
- Shape search across 10,000+ shapes from AWS, Azure, GCP, and other design libraries
- Supports XML, CSV, and Mermaid diagram formats for input
- Published on npm as `@drawio/mcp` for easy installation

### Integration Approaches

| Approach | Use Case |
|----------|----------|
| **MCP App Server** | Renders diagrams inline in chat conversations (hosted at mcp.draw.io) |
| **MCP Tool Server** | Opens diagrams directly in the draw.io editor for manual editing |
| **Skill + CLI** | Generates native `.drawio` files with optional PNG/SVG/PDF export |
| **Project Instructions** | No-installation alternative using Python code execution |

### Why This Matters

Diagrams are essential for technical communication, but manually drawing them is time-consuming. This MCP server lets AI agents generate professional diagrams directly from conversation, bridging the gap between text descriptions and visual documentation.
