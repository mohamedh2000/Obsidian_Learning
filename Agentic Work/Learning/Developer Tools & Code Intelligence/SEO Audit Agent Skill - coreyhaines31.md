## Key Points
- **Five priority audit areas**: Crawlability/indexation, technical foundations, on-page optimization, content quality, authority signals
- **Site-type specialization**: Offers tailored recommendations for SaaS, e-commerce, content sites, and local businesses
- **Schema validation caveat**: Emphasizes that `web_fetch` cannot reliably detect JavaScript-injected schema markup—recommends browser tools or Google Rich Results Test
- **Actionable output format**: Delivers findings as prioritized action plans with impact levels and specific remediation steps

### Audit Checklist Highlights
- **Crawlability**: Robots.txt, sitemap presence, indexation status
- **Technical**: Site speed, mobile-friendliness, HTTPS, URL structure
- **On-page**: Title tags, meta descriptions, heading hierarchy, internal linking, image optimization
- **Content**: Quality signals, keyword targeting, freshness
- **Authority**: Backlink profile, domain authority indicators

### Usage Context
Before running an audit, gather:
1. **Site context**: Type, business goals, priority keywords
2. **Current state**: Known issues, traffic levels, recent changes
3. **Scope**: Full site vs. specific pages, technical focus area, available data
