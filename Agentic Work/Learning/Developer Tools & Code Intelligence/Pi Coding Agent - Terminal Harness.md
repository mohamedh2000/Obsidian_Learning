## Key Features

- **Multi-Provider Support:** Anthropic, OpenAI, Google, Azure, Bedrock, Mistral, Groq, and 15+ LLM providers
- **Session Management:** Tree-structured, shareable history with export to HTML or GitHub gists
- **Context Engineering:** Customizable system prompts, project instructions, automatic message compaction
- **Four Operating Modes:**
  - Interactive TUI
  - Print/JSON output
  - RPC protocol
  - SDK integration
- **Extensibility:** Custom extensions, skills, prompt templates, and themes bundled as packages
- **Queuing System:** Message steering and follow-up capabilities while agent works
- **Minimal Core:** Lean base with complex features through extensions

## Notes

Philosophy is keeping the core minimal while enabling complex features through extensions rather than built-in tools. Highly praised for reliability, speed, and token efficiency.
