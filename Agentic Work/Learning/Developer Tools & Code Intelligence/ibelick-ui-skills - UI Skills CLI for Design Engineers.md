## Key Points
- **CLI-driven skill routing**: Run `npx ui-skills` to browse categorized UI skills and route agents to the right one.
- **Reusable UI patterns**: Focuses on reusable UI skills, design patterns, and agent-driven workflows.
- **Tech stack**: TypeScript (~62%) with an Astro-based web framework (~33%).
- **Community traction**: 4.6K stars, 196 forks.

### Why This Matters
Complements taste-focused skill packs (see [[emilkowalski-skills - Skills for Design Engineers]]) with a CLI delivery mechanism for pulling the right UI skill into an agent workflow on demand.
