## Key Points

- Google's internal engineering practices are now public on GitHub at `github.com/google/eng-practices`
- Contains two guides: one for code reviewers, one for CL (changelist) authors
- Explains internal terminology like "LGTM" (Looks Good To Me) and "CL" (changelist)
- Focuses on how to review code effectively, not just write it
