> We've added a new command to Claude Code called /insights. When you run it, Claude Code will read your message history from the past month. It'll summarize your projects, how you use Claude Code, and give suggestions on how to improve your workflow.

## Key Points

- **Historical usage analysis**: `/insights` reads your message history from the past month—not just current session, but accumulated interaction patterns
- **Project summarization**: Identifies what projects you've been working on and how you've approached them with Claude Code
- **Usage pattern detection**: Analyzes how you use Claude Code—frequent commands, common workflows, interaction styles
- **Actionable improvement suggestions**: Provides specific recommendations to optimize your workflow based on observed patterns

### How It Works

```
┌─────────────────────────────────────────────┐
│  /insights                                  │
│              │                              │
│              ▼                              │
│  ┌─────────────────────────┐                │
│  │  Past Month Messages    │                │
│  │  • Project A (40%)      │                │
│  │  • Project B (35%)      │                │
│  │  • Misc debugging (25%) │                │
│  └─────────────────────────┘                │
│              │                              │
│              ▼                              │
│  ┌─────────────────────────┐                │
│  │  Analysis Output        │                │
│  │  • You use X pattern    │                │
│  │  • Consider Y instead   │                │
│  │  • Skill Z underused    │                │
│  └─────────────────────────┘                │
└─────────────────────────────────────────────┘
```

This is meta-cognition for coding agents—the tool reflecting on how it's being used and suggesting improvements. High engagement (11.5K likes) suggests significant user interest in self-improving workflows.
