## Key Points

- Transforms codebases into interactive knowledge graphs with searchable nodes.
- Uses hybrid Tree-sitter (deterministic parsing) + LLM (semantic analysis) approach.
- Multi-agent pipeline with specialized agents: project-scanner, file-analyzer, architecture-analyzer, tour-builder, graph-reviewer, domain-analyzer, article-analyzer.
- Features guided tours showing architecture in dependency order, domain analysis mapping code to business processes, and diff impact analysis.
- Works natively with Claude Code plus Cursor, VS Code + Copilot, Codex, OpenCode, Gemini CLI, and others.
- MIT licensed, primarily TypeScript (70%).
