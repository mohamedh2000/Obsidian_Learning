## Key Points

- **Expo Skills** are executable capabilities that extend Expo's CLI and development tooling
- Skills pattern mirrors Claude Code's approach — modular, composable extensions that can be invoked by name
- Expo is the leading React Native development platform, used for cross-platform mobile apps
- The "don't sleep on" framing suggests Skills are underutilized relative to their power

### Context: The Skills Pattern

The "skills" concept has spread across developer tooling (Claude Code, Expo, VS Code extensions). Skills are self-contained capability modules that can be discovered, invoked, and composed — letting tools grow functionality without bloating the core.

**Try them:** Check Expo's documentation for available skills and how to author custom ones.
