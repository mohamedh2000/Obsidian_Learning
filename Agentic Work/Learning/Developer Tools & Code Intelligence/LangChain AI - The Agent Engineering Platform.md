## Key Repositories

- **LangChain/LangChain.js** – Reusable components for creating LLM applications
- **LangGraph/LangGraph.js** – Framework for constructing language agents as graphs

- **Open SWE** – Asynchronous coding agent
- **MCP Adapters** – Tool compatibility layer
