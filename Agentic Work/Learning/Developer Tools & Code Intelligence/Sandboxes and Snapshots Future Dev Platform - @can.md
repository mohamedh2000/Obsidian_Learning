## Key Points
- Identifies sandboxes + snapshots as the primitive building blocks of next-gen dev platforms
- "First versions" suggests early 2026 as inflection point where this pattern became visible
- Sandboxes provide isolated execution environments for AI agents to safely modify code
- Snapshots enable state preservation, rollback, and branching of development states
- This pattern maps to existing AI coding tools like Claude Code's worktrees, Cursor's checkpoints, and cloud sandboxes
- Handwavy but directionally correct — multiple AI coding products converging on this architecture

### Why Sandboxes + Snapshots

The combination solves core problems in AI-assisted development:

1. **Sandboxes** — Agents need isolated environments to test changes without breaking main codebase
2. **Snapshots** — Users need ability to revert AI changes, compare versions, and branch explorations
3. **Together** — Creates a "version control for AI sessions" primitive that enables fearless experimentation
