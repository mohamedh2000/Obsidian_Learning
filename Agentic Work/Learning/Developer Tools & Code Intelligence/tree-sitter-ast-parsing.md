# Tree-sitter AST Parsing

> Tree-sitter is the parsing layer behind a lot of modern code intelligence because it incrementally maintains syntax trees fast enough for editors, linters, and semantic tooling.

Research topic around Tree-sitter, an incremental parsing library that produces syntax trees for source code and powers editors, linters, code navigation, and AST-aware tooling.

## Key Points

- Incremental parsing lets tools update the tree after small edits instead of reparsing the entire file, which is why Tree-sitter works well in interactive editing workflows.
- Its language grammars and query model make it useful for syntax highlighting, symbol extraction, code search, structural transforms, and static analysis.
- This is directly relevant to code-intelligence systems like Context+ because AST structure gives much higher precision than raw text matching alone.
