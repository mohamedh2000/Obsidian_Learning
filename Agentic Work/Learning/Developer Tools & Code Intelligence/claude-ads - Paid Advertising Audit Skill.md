## Key Points

- Performs in-depth audits of paid advertising accounts with 250+ platform-specific checks
- Generates "Ads Health Score" (0-100) with actionable recommendations and weighted severity scoring
- Supports Google Ads, Meta Ads, LinkedIn, TikTok, Microsoft/Bing Ads, Apple Ads
- Parallel subagent analysis for simultaneous platform audits
- Industry-specific templates (SaaS, eCommerce, local services, healthcare)
- Privacy-focused local analysis — no external data transmission
- PDF report generation and MCP server integration for live API data
