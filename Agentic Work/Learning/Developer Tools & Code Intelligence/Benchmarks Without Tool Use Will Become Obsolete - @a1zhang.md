## Key Points

- The post predicts that benchmark setups "of this form" will become obsolete because they understate what models can do with tools and larger working budgets.
- The linked Esolang Benchmark clarification says its conclusions were drawn under a constrained setup: 32k token budget and no bash or Python access.
- The practical takeaway is that future coding-agent evals should distinguish raw-model performance from tool-augmented agent performance instead of conflating them.
