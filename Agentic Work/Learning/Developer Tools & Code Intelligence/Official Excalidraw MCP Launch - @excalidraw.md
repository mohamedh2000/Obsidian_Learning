## Key Points
- Anthropic collaborated with Excalidraw to build an official MCP integration, making it a first-party connector
- The MCP is available in Claude's web interface via the Connectors menu and works in Claude Code as well
- This gives AI agents native ability to create and manipulate Excalidraw diagrams without manual export/import
- The tweet signals "more to come" — suggesting this is part of a broader push to add visual tool integrations
- High engagement (6K+ likes) indicates strong community demand for visual/diagramming capabilities in agent workflows

### Why This Matters
Diagram generation has been a weak spot for text-based AI — most solutions involve generating Mermaid/PlantUML then rendering separately. A native MCP means Claude can create, edit, and collaborate on diagrams in real-time with the user. This is especially powerful for architecture discussions, whiteboarding, and design documentation directly in the agent loop.
