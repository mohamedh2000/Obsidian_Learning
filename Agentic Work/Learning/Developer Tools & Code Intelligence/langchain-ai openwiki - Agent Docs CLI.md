## Key Points

- Dual-mode: "code mode" for repo-specific docs and "personal mode" for a local knowledge wiki from sources like Gmail, Notion, and Web Search
- Multi-provider AI support — OpenAI, Anthropic Claude, Google Gemini, AWS Bedrock, OpenRouter, plus custom endpoints
- CI/CD integration (GitHub Actions, GitLab CI, Bitbucket Pipelines) to auto-generate and maintain docs via scheduled PRs/MRs
