## Key Points
- Claude Code's full system prompts are already shipped in the current release binary but intentionally disabled
- The prompts can be unlocked by modifying the binary, demonstrated via the CC Mirror fork
- @NicerInPerson patched CC Mirror to expose these hidden system-level instructions
- This reveals Anthropic ships more capability than the default experience exposes, gated by configuration flags

### Why This Matters
Understanding Claude Code's system prompts gives insight into how Anthropic structures agent behavior, skill invocation, and safety guardrails. Binary patching approaches like CC Mirror allow power users to study and customize agent behavior beyond official config options.
