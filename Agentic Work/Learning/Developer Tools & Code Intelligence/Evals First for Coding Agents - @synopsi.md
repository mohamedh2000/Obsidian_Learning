## Key Points

- The author's workflow evolved from plan-first execution to putting eval design at the very start of the process.
- Clearer guardrails make agents write stronger specs and produce code that needs much less cleanup.
- The post also notes that manually over-specifying the product too early can make the agent perform worse than letting it draft from well-formed constraints.
