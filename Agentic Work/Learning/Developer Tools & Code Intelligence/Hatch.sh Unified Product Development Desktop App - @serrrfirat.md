## Key Points
- **4-stage unified workflow**: Ideate → Design → Build → Ship in one desktop app, eliminating context-switching between separate tools
- **AI-powered brainstorming canvas**: Idea Maze with visual nodes, semantic relationships, and multi-perspective AI critiques (Skeptic, Pessimist, Competitor, User, Maintainer)
- **BYOA (Bring Your Own Agent)**: Integrates Claude Code, Cursor, or OpenCode — works with your preferred AI coding assistant
- **One-click deployment**: Ships to Cloudflare, Railway, or HereNow directly from the app

### Feature Breakdown
| Stage | Tool | Capability |
|-------|------|------------|
| Ideate | Idea Maze | Visual canvas + AI connections |
| Design | Superdesign | 60,000+ community design prompts |
| Build | BYOA Mode | Live preview, tabbed editor, diff view |
| Ship | Deploy | Multi-provider with status tracking |

### Tech Stack
Tauri 2, React 18, Zustand, TailwindCSS, Hono, Drizzle ORM, Turborepo, pnpm
