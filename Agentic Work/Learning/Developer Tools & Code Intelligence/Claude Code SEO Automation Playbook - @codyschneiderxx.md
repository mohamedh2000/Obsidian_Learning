## Key Points
- **Keyword Universe Discovery**: Use Keywords Everywhere's related keywords + "People Also Search For" endpoints, then pipe results to DataForSEO's SERP API to identify ranking gaps. Claude Code can generate a full content calendar with clustering and prioritization in one workflow.
- **Programmatic Landing Pages**: For SaaS serving multiple verticals, pull long-tail keyword variations per industry, check difficulty via DataForSEO, then have Claude generate unique pages with semantic terms and schema markup already embedded.
- **Link Building via Domain Intersection**: DataForSEO's domain intersection endpoint reveals sites linking to competitors but not to you. Claude Code can scrape contact info and draft personalized outreach referencing the specific linked page — entire pipeline in ~8 minutes.
- **Internal Linking Maps**: Use Keywords Everywhere's related keyword data to build topical relevance clusters, then have Claude generate the actual internal linking structure based on semantic relationships (not random links).
- **Technical Audit + Auto-Fix**: Run DataForSEO's on-page API, then Claude generates fixes for every issue found — missing canonicals, broken schema, thin content, orphan pages. Find the problem, write the code to fix it.
- The author recommends tracking everything via Graphed.com for SEO reporting consolidation.

### Why This Matters
This thread demonstrates the "API key + Claude Code = automation" pattern at its most aggressive. The 8-minute link building pipeline is especially notable — that's not "faster" than manual, it's a different category entirely.
