> Toolkit for "vibe coding" workflows: security scanner (3500+ rulesets, OWASP Top 10), persistent memory across sessions, custom skill spawner, and Supabase security testing — integrated via MCP.

**Topics:** [[Developer Tools]], [[Security]]

## Key Points
- **Scanner:** Detects vulnerabilities in AI-generated code with 3500+ security rulesets and OWASP Top 10 coverage
- **Mind:** Persistent memory across Claude sessions — retains context, decisions, and preferences
- **Spawner:** Generates custom skills and agents tailored to your specific codebase
- **Suparalph:** Dedicated security testing module for Supabase databases

### Workflow: Ideate → Remember → Specialise → TestDB → Scan → Ship
1. **Idearalph:** Converts rough ideas into validated product specs
2. **Mind:** Maintains context so you don't repeat yourself across sessions
3. **Spawner:** Creates specialized skills for your project
4. **Suparalph:** Tests Supabase RLS and auth configs
5. **Scanner:** Catches security issues before deploy
6. **Knowledge Base:** Educational resources on secure development

### Why It Matters
Addresses two pain points of rapid AI-assisted development: (1) context loss between sessions, and (2) security blind spots in generated code. MCP integration means it plugs directly into Claude Code and similar agents.
