# HALO - Self-Improving Agents via Harness Optimization

> AI Agents are composed of two key elements: a model and a harness. The model decides what to do; the harness does it. Billions have been spent improving models—not as much on harnesses, until now.

## Key Points

- HALO (Hierarchical Agent Loop Optimizer) is an agent that optimizes other agents by analyzing execution traces
- Based on the "Mismanaged Genius Hypothesis" from @a1zhang: LLMs may possess superhuman intelligence, but humans aren't great at managing their harnesses
- The core loop: collect traces → analyze with HALO → identify failure modes → produce harness fixes → apply via coding agent → repeat
- Many harness problems only emerge across aggregate execution patterns, not individual traces
- Achieved 10%+ improvements on AppWorld, TerminalBench, Finance Bench, and more
- The harness is becoming "an optimizable service layer: comparable in importance to the model itself"
