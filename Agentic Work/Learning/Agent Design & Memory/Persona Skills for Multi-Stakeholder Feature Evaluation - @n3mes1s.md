## Key Points
- Persona skills simulate distinct stakeholder roles (e.g., PM, engineer, user, exec) to stress-test feature ideas
- Each persona brings different priorities and viewpoints, surfacing conflicts early in the design process
- The pattern catches blind spots that single-perspective prompting misses
- Effectively turns the agent into a mini design review committee before implementation begins

### How It Works
Rather than asking "is this a good feature?", the persona skill orchestrates multiple simulated stakeholders who each evaluate the feature from their role's perspective. Disagreements between personas highlight real tensions (e.g., engineering complexity vs. user value) that need resolution.
