# Hermes Agent Backup and Transfer

> You can backup and transfer your Hermes agent cleanly — `hermes backup` creates a zip, install fresh on new machine, transfer zip, run `hermes import`, done.

## Key Points

- `hermes backup` creates a portable zip of your agent
- Transfer to new VPS or Mac Mini by installing fresh + `hermes import`
