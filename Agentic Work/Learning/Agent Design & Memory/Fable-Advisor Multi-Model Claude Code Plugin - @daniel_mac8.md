## Key Points

- fable-advisor is a free, open-source Claude Code plugin built around an agentic engineering pattern.
- It empowers Fable to pick an implementer from Opus 4.8, GPT-5.5, or Sonnet 5 based on task complexity.
- Fable itself acts as the advisor/router rather than always doing the implementation.
- At the end, Fable performs a read-only review pass over the generated output.
