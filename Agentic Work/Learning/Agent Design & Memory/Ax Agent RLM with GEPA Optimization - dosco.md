# Ax Agent RLM with GEPA Optimization

The ax agent — an RLM (Reasoning Language Model) agent built around a JS REPL — has had built-in GEPA (Gradient-free Efficient Prompt Automation) for a while. It even includes added functions along with everything else that touches the prompt into its optimization.

## Key Points

- Ax agent combines RLM architecture with JS REPL for execution
- GEPA enables gradient-free prompt optimization at runtime
- Functions and prompts are jointly optimized in the same loop
