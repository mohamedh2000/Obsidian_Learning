## Key Points

- Have Fable audit your repo and write a full skill library while access lasts.
- The persona prompt matters: "you're a retiring principal engineer leaving everything behind for the team" shifts it into a different, more thorough mode.
- Output is ~10–16 skill files: debugging playbooks, change rules, and the failure stories that cost real time.
- Every judgment call it would have made on its own becomes written down and usable by cheaper models (Opus, Sonnet).
- Cost framing: one run, ~30% of weekly usage — the model stays useful long after it goes behind credits.
