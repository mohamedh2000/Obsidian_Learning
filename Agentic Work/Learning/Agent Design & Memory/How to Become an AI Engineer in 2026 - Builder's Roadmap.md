## Key Points

- Modern agent engineers build, harness, and operate agent systems on top of frontier models — not just glue together framework roles
- The four context primitives: Write, Select, Compress, Isolate
- Key skills: agent loop design, tool dispatch, context engineering, sub-agent orchestration, memory/durability/sandboxing, evals/traces/CI gates
- 6-phase roadmap with 17 weeks of focused work to reach production-level agent engineering
