# Building Your First Skill Library for AI Agents

> Start with repetitive, high-judgment work—not prompts. A skill library captures the sequence of judgment that makes experienced humans valuable.

## Key Points

- **Don't start with prompts**: Organizing common prompts creates an abandoned warehouse—tasks too "light"
- **Start with judgment-heavy work**: Risk, context, owner calls, and stop rules
- **High-judgment examples**: PRD reviews, launch QA, support escalations, code reviews, brand voice reviews, sales call prep

## The Real Questions Skills Should Capture

- Should we push forward, or stop and ask a human?
- Should this trust the CRM or the latest Slack message?
- Is this feedback a minor tweak, or has direction drifted?
- Is this customer frustrated or an actual churn risk?
- Can the agent revise directly, or must a human decide?

## Why It Matters

If these judgments only live in someone's head:
- Senior goes on PTO → review quality drops
- Project pauses → agent references outdated statuses
- Prompt copy-pasted → old preferences pollute new work
- Feedback taken too literally → useless revision cycles

## The Right Question

Not: "What prompts can I organize?"

Instead: "What task recurs frequently where I still feel the need to personally double-check it?"
