## Key Points

- SIA operates on a different layer than typical agent frameworks—it focuses on structured feedback loops for self-evaluation and adaptation
- After every run, SIA updates three things: its own harness, underlying model weights, and memory layer
- Climbed to the top of MLE-Bench (OpenAI's benchmark for ML model training agents)
- Beat specialized ML research agents including MLEvolve and AIRA-dojo
- The agent rewrites itself based on learned insights
