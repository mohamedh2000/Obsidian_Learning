## Key Points

- The post relays Morgan Linton's claim that longer root-level `AGENTS.md` files can create context tax and "context rot" instead of better execution.
- It contrasts static instruction bloat with dynamic context engineering, structured memory, tool optimization, and compressed histories.
- The practical recommendation is to keep `AGENTS.md` narrowly focused on repo-specific exceptions, commands, and constraints that cannot be inferred elsewhere.
