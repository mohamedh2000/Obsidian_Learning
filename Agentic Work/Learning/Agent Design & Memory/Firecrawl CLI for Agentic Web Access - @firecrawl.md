## Key Points
- Firecrawl provides a CLI for agents to fetch, scrape, and process live web content
- Docs available at https://docs.firecrawl.dev/sdks/cli
- Enables agents to work with real-time web data rather than cached or pre-processed content
- This bridges the gap between agents and the live internet, enabling research and data-gathering workflows

### Why It Matters
Most agent tools provide static context (files, repos, docs). Firecrawl CLI gives agents dynamic web access: fetching pages, extracting structured data, and crawling sites. This capability is foundational for research agents, monitoring agents, and data-enrichment workflows.
