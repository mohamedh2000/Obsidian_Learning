## Key Points

- Hermes hit 100K GitHub stars in 53 days, now at 160K+ stars, 26K+ forks
- Unlike typical agents, Hermes remembers everything with a learning loop
- When completing complex tasks, enters reflective phase to form reusable skills
- Telegram integration turns Hermes into a personal assistant from your phone
- Covers: Installation, Telegram Setup, Personal Bot, Virality Analyzer use cases
- Skills can be browsed, searched, installed, and managed via CLI

## Skills System

```bash
hermes skills browse                              # Browse all hub skills
hermes skills search kubernetes                   # Search all sources
hermes skills install openai/skills/k8s           # Install with security scan
hermes skills list --source hub                   # List installed hub skills
```
