## Key Points

- Framework for designing structured feedback loops enabling autonomous self-improvement
- Three-layer improvement: harness updates, model weight updates, memory layer updates
- Demonstrated top performance on MLE-Bench
- Compares favorably against MLEvolve, AIRA-dojo, and Karpathy's autoresearcher
