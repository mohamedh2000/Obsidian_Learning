> DSPy was never a general agent framework it was a great way to reason about working with LLMs and not surprisingly stuff like RLMs came out of it which make all other context stuffing large model needing "agentic" thingies feel like amateur hour

## Key Points

- DSPy was designed for reasoning about LLM workflows, not as a general agent framework
- RLMs (Reasoning Language Models) emerged from DSPy's approach
- RLMs outperform "context stuffing" agentic approaches that rely on large models
