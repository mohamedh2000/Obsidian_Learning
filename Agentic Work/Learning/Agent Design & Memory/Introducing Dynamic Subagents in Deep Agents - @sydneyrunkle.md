## Key Points

- Deep Agents uses dynamic subagents to handle work that is too broad or context-heavy for a single agent loop.
- Instead of issuing one tool call at a time, the agent writes a short script that dispatches subagent work through a lightweight interpreter.
- This makes fan-out, multi-phase workflows, conditional routing, and synthesis more deterministic at scale.
- The article frames common patterns such as classify-and-act, fanout-and-synthesize, adversarial verification, generate-and-filter, tournaments, and loop-until-done.
