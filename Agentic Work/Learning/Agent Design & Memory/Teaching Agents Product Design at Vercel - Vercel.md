## Key Points

- Product-design context needs to live somewhere agents can retrieve it, because code alone shows what shipped but not why a pattern became standard.
- Vercel's `product-design` system combines an agent skill, automatic lint rules, Vercel Agent reviews, evals, and a human-governed update loop.
- The article frames repeated product decisions as reviewable repository knowledge, with collector and judge prompts gathering evidence before humans approve guideline changes.
