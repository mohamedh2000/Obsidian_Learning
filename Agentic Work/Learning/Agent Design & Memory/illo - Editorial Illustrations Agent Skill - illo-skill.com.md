## Key Points

- **Recurring Character Mascots**: Uses on-model characters (like Blot the ink drop, Pip the bird) that maintain consistency across all generated illustrations — no more one-off AI images that look disconnected
- **Load-Bearing Moment Detection**: Reads articles to identify the key moments worth illustrating, then renders them as single scenes or explainer diagrams with flow arrows
- **Automatic Palette Mapping**: Same character adapts to different destinations — bold fluorescent pink for social, your blog's exact brand colors for posts
- **Open Ecosystem**: Choose from 30+ community character packs or build your own, keep them private or publish

### How It Works
```
illo Illustration Pipeline:
┌─────────────────────────────┐
│   Article/Idea Input        │
├─────────────────────────────┤
│   Key Moment Detection      │  ← finds "load-bearing" scenes
├─────────────────────────────┤
│   Character Selection       │  ← your mascot or community pack
├─────────────────────────────┤
│   Palette Mapping           │  ← matches destination brand
├─────────────────────────────┤
│   Scene/Diagram Rendering   │  ← emotional or explainer style
└─────────────────────────────┘
```

### Why This Matters
Most AI image generation produces generic, disconnected visuals. illo solves the "cohesion problem" by using recurring characters that readers recognize across your content. The skill format means it integrates directly into agent workflows — no manual image prompting. The open character ecosystem is the clever part: you can commission a custom mascot once and use it forever.
