> DSPy turns prompts into programs. GEPA optimizes those programs without RL. RLM reasons over inputs bigger than any context window.

## Key Points

- **dspy-agent-skills**: Five Agent Skills that give any compatible coding agent working knowledge of idiomatic DSPy
- **The Problem**: Getting Claude Code and Codex CLI to write idiomatic DSPy code is frustrating — agents use deprecated imports and wrong return types
- **DSPy**: Programming, not prompting — declare input/output contracts as typed Signatures, compose Modules, let an optimizer tune prompts and few-shot examples
- **GEPA**: Genetic-Pareto optimizer that uses language model reflection on failures instead of RL — outperforms GRPO by 6% average (up to 20%) with 35x fewer rollouts
- **Key insight for GEPA**: Metrics must explain *why* something failed, not just return a score
