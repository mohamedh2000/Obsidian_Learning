## Key Points

**DP Code**
- Started as T3 Chat clone, now looks like Codex app
- Connects Gemini, Claude, OpenAI, and OpenCode
- Split work across multiple chats, run agents in parallel
- Switching providers mid-task supported

**Emdash**
- YC-backed, runs multiple coding agents in parallel
- Supports 20+ AI providers in a single project with separate Git workflows
- UI-based plugin, MCP, and skills installation
- Sluggish on Windows (separate terminals per agent)

**Letta Code**
- Memory-first coding agent similar to Hermes Agent
- Auto-detects logged-in AI providers
- Similar to OpenCode with stronger memory handling
- Supports cron jobs for automation workflows

**Superset**
- Similar to Emdash in positioning
- macOS-only currently
- Monitors multiple agents from a single interface
- Each agent's changes are isolated
