- **40+ specialized agents across 8 departments**: Engineering (7), Design (5), Marketing (7), Product (3), Project Management (3), Studio Operations (5), Testing (5), Bonus (2)
- **Markdown-based definitions with YAML frontmatter**: Each agent is a separate .md file with name, description, color, tools, and 500+ word system prompts
