## Key Points

- Built two Hermes Agent profiles that use Ollama cloud models for research-oriented tasks.
- Stage 1 runs a parallel panel with `qwen3.5:cloud` and `deepseek-v4-pro:cloud`, each producing verifiable answers with confidence and sources.
- Stage 2 uses a Kimi judge model to fact-check claims, flag contradictions, identify corrections, and output structured JSON.
- Stage 3 has the outer model synthesize the judge output into polished final prose.
