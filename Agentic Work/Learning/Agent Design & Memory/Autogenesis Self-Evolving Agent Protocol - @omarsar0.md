## Key Points

- Autogenesis is a self-evolving agent protocol with an ongoing loop: assessment → proposal → validation → integration
- No retraining or human patching required - agents identify capability gaps and safely rewrite themselves
- Part of a growing wave of self-improving systems alongside Meta-Harness and Darwin Gödel Machine
- Static agents age quickly as deployment environments change and new tools arrive
