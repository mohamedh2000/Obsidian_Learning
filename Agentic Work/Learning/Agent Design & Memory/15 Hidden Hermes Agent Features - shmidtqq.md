## Key Points

### Part 1: Setup You Skipped
1. **/personality + SOUL.md** — Persistent persona across sessions/platforms
2. **MEMORY.md + USER.md** — FTS5 + LLM summarizer indexed memory files
3. **/insights [days]** — Cross-session analytics (tokens, stalls, patterns)
4. **/snapshot** — Save full agent state, rollback anytime

### Part 2: Mid-Flight Controls
5. **/branch (alias /fork)** — Branch session like git commits
6. **/rollback** — Filesystem checkpoints for touched files
7. **/btw** — Ephemeral side question, uses context, no tools, no persistence
8. **/steer and /queue** — Redirect running agents, queue next turns
9. **/yolo, /fast, /reasoning** — Power toggles for approvals, speed, effort

### Part 3: Provider Lock-In That Isn't
10. **/model [--provider] [--global]** — Swap models mid-session: Anthropic, OpenAI Codex, OpenRouter, NVIDIA NIM, Kimi, Gemini, Bedrock, Vercel AI Gateway

## Notes

Hermes is a provider-agnostic AI agent with 100+ pre-built skills, runs on 17 messengers from one process, swaps models mid-session.
