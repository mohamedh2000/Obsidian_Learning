## Key Points

### Kimi K2.6 Specs
- 1 trillion parameters, 32 billion activated per token
- SWE-Bench score of 65.8
- Reads entire client codebase, understands architecture, writes production code
- $150-300 API costs per project vs $4,800 traditional developer cost

### Agent Architecture
- 300 parallel agents per run deliver 100+ files simultaneously
- Search, analysis, coding, and writing all in parallel
- Obsidian visualizes entire knowledge graph in real time while agents work

### Business Model
- Traditional agency: 10-15 people, 30% margin after salaries
- Solo AI agency: 90% margin — $72,000 monthly profit with $500 overhead
- By month 10: Kimi handles 80% technical work, human manages strategy and client relationships

### Obsidian Integration
- Maps every project, every client, every agent in one graph
- Graph updates itself in real time during agent execution
