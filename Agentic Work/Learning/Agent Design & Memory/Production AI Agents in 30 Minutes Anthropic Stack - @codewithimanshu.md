## Key Points

- **4-Part Production Stack**: Agent Development Kit (ADK) for building/evaluating, Model Context Protocol (MCP) for tool/data integration, Vertex AI Agent Engine for deployment/monitoring, Agent-to-Agent (A2A) Protocol for cross-framework agent communication.
- **MCP + Claude Integration**: ADK supports Claude models via Vertex AI; MCP provides one standard for agents to talk to any tool or data source.
- **Multi-Agent Architecture**: Shows how to build an orchestrator agent routing between specialized agents with proper state/context handoffs — the pattern where 99% of builders fail.
- **Deployment Without DevOps**: Vertex AI Agent Engine handles minimal-code deployment with automatic latency/CPU/memory monitoring, logging, and observability.
- **A2A Protocol**: Open protocol enabling agents built on different frameworks (Claude agent, LangChain agent, CrewAI agent) to communicate seamlessly without custom integration code.
