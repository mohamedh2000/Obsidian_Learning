## Key Points

- The #1 AI coding failure mode is the agent confidently picking the wrong path at an ambiguous decision point, wasting 10+ minutes of work.
- GStack implements an "ambiguity gate" — agents stop and ask when they hit forks in architecture, data modeling, or destructive operations with unclear scope.
- Not a blunt "confirm everything" approach, but scoped specifically to decisions where guessing wrong actually costs time.
