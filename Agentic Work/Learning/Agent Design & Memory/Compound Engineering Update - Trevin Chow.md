> Compound Engineering is getting much better at carrying context across the whole loop — not just "agent writes docs" or "agent writes code" but getting the agent pointed at the right thing, giving it the vocabulary of the repo, catching bad shape before it turns into work.

## Key Points

- **CONCEPTS.md** — new primitive for shared vocabulary at repo level; lightweight glossary of important nouns, flows, and distinctions
- Agent mistakes often aren't syntax errors — they're picking the wrong meaning of a normal-looking word
- `ce-compound` and `ce-compound-refresh` can create, seed, and improve CONCEPTS.md as real work happens
- **ce-plan got more flexible** — now has an answer-seeking path that can do research/synthesis without creating a plan doc you didn't ask for
- Handles external-research requests better: competitors, prior art, framework comparisons, best practices
- Hit 20k stars on GitHub (was 10k when @kieranklaassen invited Trevin to co-pilot)

## The Harder Parts of Agent Context

1. Getting the agent pointed at the right thing
2. Giving it the vocabulary of the repo
3. Catching bad shape before it turns into work
4. Looking at the actual product before merge/finish
5. Telling the world about what you've shipped
