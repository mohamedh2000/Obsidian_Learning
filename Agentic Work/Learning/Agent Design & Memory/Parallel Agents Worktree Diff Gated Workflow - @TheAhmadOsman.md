# Parallel Agents — Worktree + Diff-Gated Workflow

> Ahmad describes his parallel-agents workflow: tell an agent to fan out or use deterministic scripts, spin up workers, isolate in git worktrees, gate with diffs, add backups/rules/logs, merge what passes. Turning it into a Claude Code Skill.

## Key Points

- Fan-out via agent OR deterministic scripts
- Each worker runs in its own git worktree (isolation)
- Diff-gated merging — only passing work lands
- Backups, rules, logs for deterministic runs
- Being turned into a reusable Claude Code Skill
