## Key Points
- Andrej Karpathy's guidelines for working with coding agents are formalized into a skills repository structure
- The repo `forrestchang/andrej-karpthy-skills` extracts Karpathy's best practices into reusable skill definitions for Claude Code
- This skill-based approach packages expert workflow knowledge into executable agent instructions
- The high engagement (3.7K+ likes) reflects the community's appetite for principled agent engineering guidance

### Why It Matters
Karpathy's agent advice emphasizes agent-native thinking: parallel delegation, prompt quality over tool quantity, and treating bad results as workflow problems. Packaging these ideas as Claude Code skills makes them executable rather than aspirational.
