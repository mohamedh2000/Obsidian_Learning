# Hermes Agent Goal Loop with Supervisor Model

> New /goal feature in Hermes Agent: starts a loop with a supervisor model determining task completion, forcing continuation until done.

## Key Points

- New `/goal <prompt>` command starts a supervised agent loop
- Supervisor model evaluates task completion at end of each agent loop iteration
- Forces agent to continue until task is actually done (inspired by Ralph loops and Codex's /goal feature)
- PR: [NousResearch/hermes-agent#18262](https://github.com/NousResearch/hermes-agent/pull/18262)
