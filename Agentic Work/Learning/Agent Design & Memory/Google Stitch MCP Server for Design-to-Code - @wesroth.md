## Key Points

- **Google's official MCP server** for Stitch — their design-to-code platform
- Pipes designs directly into your IDE, giving coding agents **full visual context**
- Key capabilities:
  - **Generate new screens** from design specs
  - **Fetch code from any design** in the Stitch system
  - **Full visual context** for agents — they can "see" the UI they're building
- Works across **Claude, ChatGPT, VS Code, Cursor** and other MCP-compatible clients
- Positions agents as "UI-savvy collaborators" rather than blind code generators

### Why This Matters

MCP (Model Context Protocol) enables tools to expose capabilities to LLMs in a standardized way. By wrapping Stitch's design assets as MCP tools, Google lets any compatible agent access design specs, generate matching code, and understand visual context — bridging the gap between design files and implementation.
