## Key Points
- **Remotion Agent Skills Ecosystem**: Remotion (programmatic video framework) has launched Agent Skills — allowing AI agents to compose and render videos through tool interfaces

### Why This Matters
Video creation has been a gap in AI agent capabilities — most agents can generate text, code, and images, but video requires orchestrating multiple systems (scripts, assets, rendering, export). Remotion's skill framework abstracts this complexity into tool calls agents can use.
