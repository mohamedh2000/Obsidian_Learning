# Skill Graph Content Engine - AI Agent for Multi-Platform Content

> A skill graph is a playbook for your AI agent - a folder of interconnected markdown files where each file is one knowledge node in your content system's brain.

## Key Points

- **The Problem**: Using AI for content without context is like "hiring a genius with amnesia every single time." Generic prompts produce generic outputs requiring heavy editing.

- **Skill Graph Solution**: A folder of interconnected markdown files where each file is one "knowledge node." Uses `[[wikilinks]]` to reference other nodes (e.g., `[[brand-voice]]`, `[[hooks]]`).

- **How It Works**: When AI agent is pointed at the folder, it follows links, reads connected nodes, and builds complete understanding of brand, voice, audience, platform rules, hook formulas, and repurposing logic BEFORE writing.

- **System Components**:
  - 30+ interconnected .md files
  - Brand voice, audience, platform strategies all documented
  - Repurposing engine: one topic → 10 platform-native posts

- **Results Claimed**: Running 10 social media accounts without manual post writing, no content team, no agency retainer. One idea → 10 platform-specific posts.

- **Key Insight**: The difference between bad and good AI content is context. Bad = single prompt with no brief. Good = graph of knowledge nodes = hiring someone with complete onboarding.
