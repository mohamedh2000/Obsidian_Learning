> "Turns agent activity into a map of crossings: prompts, tool calls, tool results, failures, model switches, subagents, approvals, memory hits, redactions, context compression, cron runs, and reportable evidence."

## Key Features

- **Journey Index:** Track recent agent work across multiple sources
- **Labyrinth Map:** Visualize ordered agent activity sequences
- **Inspector Tool:** Examine crossing details including input, output, duration
- **Skill Atlas:** Display bundled, optional, external, and custom skills
- **Cron Gate:** Manage scheduled autonomy with run history
- **Model Ferry:** Track model/provider transitions
- **Report Generation:** Markdown and JSON reports with secret redaction

## What It Does

A read-only dashboard plugin for Hermes Agent functioning as "a blackbox recorder for autonomous work." Rather than being a chat interface, it monitors and visualizes agent behavior patterns, providing transparency into how autonomous agents navigate tasks and make decisions.
