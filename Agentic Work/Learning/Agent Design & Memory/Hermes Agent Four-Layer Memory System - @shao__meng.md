## Key Points

- Hermes keeps the prompt prefix stable for cache efficiency, pushing volatile history and large context into tools instead of the live prompt.
- The four layers cover frozen memory files, searchable session history in SQLite, procedural memory via skills, and optional deeper user modeling.
- The comparison with OpenClaw highlights a sharper separation between hot facts, cold retrieval, and prompt-cache-aware engineering tradeoffs.
