### Linked Repo: OthmanAdi/planning-with-files

**Core Innovation:** Uses filesystem as "working memory" — agents persist plans, findings, and progress in markdown files. Prevents:
- Goal drift between sessions
- Error repetition
- Context overload from lost state

**Lifecycle Hooks:** IDE hooks re-read plans before tool use and verify completion after tasks.
