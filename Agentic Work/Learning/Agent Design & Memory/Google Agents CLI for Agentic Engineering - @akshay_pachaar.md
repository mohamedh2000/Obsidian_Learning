## Key Points

- Karpathy framed agentic engineering (spec design, eval loops, security oversight) as what separates production agent work from vibe coding.
- The pain: every phase needed a different tool — editor, terminal, browser, cloud console, eval framework — so every transition is a context switch.
- Google's ADK Agents CLI covers the whole workflow in one place: one setup command injects 7 ADK-specific skills into a coding agent's context.
- Demo built a RAG agent from scratch with Claude Code: scaffolded from the `agentic_rag` template, generated 20 LLM-as-judge eval scenarios, produced a scorecard, then deployed to Agent Runtime and registered to Gemini Enterprise.
- Repo: https://fandf.co/43Ys2m6 — full write-up covers install → enterprise registration, including an instruction loophole the eval caught before deployment.
