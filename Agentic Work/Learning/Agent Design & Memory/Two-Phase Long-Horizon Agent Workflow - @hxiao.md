# Two-Phase Long-Horizon Agent Workflow

> Han Xiao argues long-horizon agent work now splits into a web-grounded planning phase and a local-file execution phase, with local snapshots improving determinism, speed, consistency, and cost.

## Key Points

- Long-horizon agent work is shifting from repeated web grounding to a two-phase workflow
- Phase 1 uses web IO to research and materialize knowledge into local `.md`, `.json`, or `.csv` files
- Phase 2 mounts those local files and keeps the agent loop grounded on the same snapshot instead of the live web
- Local files improve determinism, iteration speed, consistency across cross-checks, and token efficiency
