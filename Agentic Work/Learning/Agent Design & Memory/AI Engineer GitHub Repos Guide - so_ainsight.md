## The 10 Essential Repos

### LLM App Frameworks
1. **LangChain** - LLM app framework, used in almost all AI engineer job postings
   - https://github.com/langchain-ai/langchain

2. **LangGraph** - Stateful agent design with graphs, for "agent workflow" requirements
   - https://github.com/langchain-ai/langgraph

3. **LlamaIndex** - RAG and document agent standard, for "search pipeline" work
   - https://github.com/run-llama/llama_index

4. **CrewAI** - Multi-agent teams with roles and tasks, used in Fortune 500 production
   - https://github.com/crewAIInc/crewAI

### Infrastructure
5. **Qdrant** - Production-grade vector DB in Rust, alongside Pinecone/Chroma/FAISS
   - https://github.com/qdrant/qdrant

6. **Ollama** - Run open-source LLMs locally with one command, growing demand for cost/privacy
   - https://github.com/ollama/ollama

### Evaluation
7. **Ragas** - RAG pipeline evaluation framework, measures hallucination/faithfulness/relevance
   - https://github.com/vibrantlabsai/ragas

### MCP & Resources
8. **Awesome MCP Servers** - Model Context Protocol servers in production
   - https://github.com/punkpeye/awesome-mcp-servers

9. **Awesome LLM Apps** - 100+ templates for RAG, agents, multi-agent, voice, MCP
   - https://github.com/Shubhamsaboo/awesome-llm-apps

10. **AI Agents for Beginners** - Microsoft's free 12-lesson course on AI agents
    - https://github.com/microsoft/ai-agents-for-beginners

## Key Skills for 2026

- RAG (Retrieval Augmented Generation)
- Agents
- Vector DBs
- Evaluation
- MCP (Model Context Protocol)
