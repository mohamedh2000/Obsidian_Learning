## Key Points
- **Installation**: Available via `npm i agentation` — straightforward npm package for any Node.js project
- **Licensing**: Fully open-source with no monetization roadmap — author explicitly committed to keeping it free
- **Community**: Issues and PRs welcome — active development with community contribution model
- **Purpose**: Provides UI primitives and patterns specifically designed for AI agent applications

### Integration Path
```bash
npm i agentation
```

The package provides the foundation for building agent interfaces without vendor lock-in. Combined with the tools listed in Craftwork's design tools roundup (which includes agentation.dev), this represents a growing ecosystem for agent-first UI development.
