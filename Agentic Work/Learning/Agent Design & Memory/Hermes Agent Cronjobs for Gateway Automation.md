## Key Points

- Traditional cron jobs work for silent machine tasks; Hermes Agent cronjobs extend this to agents
- New feature: gateway-level cronjobs that don't require an agent in the loop
- Use cases: systems diagnostic scripts reporting every 12 hours, RSS feed pulls, Telegram notifications
- Cost savings on purely programmatic tasks that don't need agent reasoning
- If script has no output, no ping is sent
