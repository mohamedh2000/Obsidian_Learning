## Key Points

- **Distributed Execution**: Agents run locally, remotely via SSH, or through cloud connectors without public IPs or firewall mods
- **Agent Communication**: Native inter-agent messaging enables swarms and hierarchical orchestration
- **Safety Layer**: Real-time heuristic detection for dangerous patterns (mass file deletion, privilege escalation)
- **Channel Integration**: Telegram and WhatsApp supported; Discord and Slack planned
- **Modular Extensions**: Skills and plugins extend capabilities without cluttering core prompts
- **Evaluation Engine**: Automated testing with customizable evaluators for LLM benchmarking
- **Docker Sandboxing**: Isolated execution with configurable resource limits
