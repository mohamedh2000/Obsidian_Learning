> Continual learning isn't only about updating model weights — the vast majority of production agents can improve without touching weights at all.

## Key Points

- Everyone talks about continual learning as if it means one thing: updating model weights.
- Inconvenient truth: the vast majority of agents in production don't (and can't easily) retrain weights.
- Implies continual learning for agents happens through other layers — memory, tools, harness, and accumulated context — rather than weight updates.
