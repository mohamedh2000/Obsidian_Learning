# OpenAI Symphony - Autonomous Coding Agent Orchestration

> Symphony turns project work into isolated, autonomous implementation runs, allowing teams to manage work instead of supervising coding agents.

## Key Points

- Orchestrates autonomous coding agents to handle project tasks end-to-end
- Enables higher-level work management rather than direct agent supervision
- Agents autonomously complete tasks and provide proof-of-work evidence (CI status, code review feedback, complexity metrics)
- Integrates with work management tools (demonstrated with Linear board)
- Supports automated safe PR landing without direct engineering oversight
- Written primarily in Elixir (95.5%), with Python and CSS
- Engineering preview status - designed for trusted environments
- Requires codebases adopting "harness engineering" practices
