## Key Points

- RLM-FORGE: pulls Reasoning Language Models out of inference into runtime
- Hermes provides: bounded calls, tools, skills, provider portability, and memory
- Ouroboros adds: recursion, retry, state, and replay
- TraceGuard: ensures parent claims cannot commit without fresh child evidence
- Memory used as operational prior for where to recurse next, not just evidence
- "Evidence before belief" — key architectural principle
- Repo: https://github.com/Q00/rlm-forge
