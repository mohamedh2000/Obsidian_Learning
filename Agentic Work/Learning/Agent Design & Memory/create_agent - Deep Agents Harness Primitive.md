> The entire design of Deep Agents comes from optionally extending the base harness primitive `create_agent` to support behaviors useful for agent engineering.

## Key Points

- `create_agent` is a simple primitive in LangChain that underlies all Deep Agents harness engineering
- Deep Agents extends this base to support:
  - Filesystem tools, bash
  - Compaction + context offloading
  - Subagents, skills, and memory support
  - Hooks
- Entry points for Tools, Middleware (hooks), Providers make it highly extensible
- Primitive has existed for over a year, codified in LangChain 1.0 release
- Open to community suggestions on what content to produce around this
