## Key Points

- Implements a Socratic teaching methodology for self-testing on completed Claude Code sessions
- Two operating modes: Solo (self-quizzing) and Teaching (structuring knowledge transfer to others)
- Uses incremental confirmation with a checklist that updates after each verified concept
- Searches session transcripts by topic (JSONL files) or accepts direct file paths
- Creates dated checklist files tracking problem understanding, solution rationale, design decisions, and broader impact
- Enforces concise responses (under 2000 characters per exchange) with adaptable explanation levels (ELI5, ELI14, intern-level)
- Credits original "Learn Quiz" prompt concept to Suzanne at Anthropic
