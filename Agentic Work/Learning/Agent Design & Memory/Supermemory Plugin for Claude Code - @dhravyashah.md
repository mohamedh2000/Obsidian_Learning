## Key Points
- **Hybrid memory architecture**: Combines episodic content (what you did) with static information (preferences, style) in user profiles
- **Problem solved**: "Every day, I have to explain the same exact things to claude code" — massive CLAUDE.md files, copy-pasting context, memory docs that agents never look at
- **Memory compounding**: "Claude code will now remember exactly how you fixed an error last time, and this knowledge compounds into an agent that feels truly insanely customized"
- **Learns your style**: Instead of generic code, adapts to preferences like "Use less useEffects!!!"
- **Knows your context**: Understands you're a founder/student/engineer and suggests appropriate tools and practices

### How It Works — Example
```
Developer: "I need to add rate limiting to this endpoint"

Agent: "Based on the rate limiting you implemented in the payments-api
last month (using sliding window with Redis), and your preference for
the express-rate-limit middleware, here's an approach that matches
your existing patterns..."
```

### Technical Foundation
- **User profiles in Supermemory**: Both episodic and static information
- **Real-time learning**: Updates knowledge as you use it
- **Hybrid memory**: The technical piece that makes persistent context work
