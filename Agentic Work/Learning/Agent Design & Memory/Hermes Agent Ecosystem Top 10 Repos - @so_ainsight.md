## Key Points

- **Hermes Agent Core** - NousResearch/hermes-agent: MIT-licensed agent with persistent memory and self-evolving skills
- **Hermes-Wiki** - cclank/Hermes-Wiki: Community wiki explaining source code implementation
- **Atlas** - ksimback/hermes-ecosystem: Ecosystem map of 100+ tools/skills with RAG search
- **Control Interface** - xaspx/hermes-control-interface: Self-hosted dashboard for multi-agent + long-task management
- **Skill Factory** - Romanescu11/hermes-skill-factory: Auto-generates new skills from task retrospectives
- **Maestro** - ReinaMacCredy/maestro: Local multi-agent coordination across Codex/Claude Code/Gemini with structured memory
- **Hermes Agent Camel** - nativ3ai/hermes-agent-camel: Fork with trust boundaries (CaMeL) for production
- **Hermes HUD** - joeynyc/hermes-hud: Textual TUI for real-time visualization of consciousness flow and memory state
- **Hermes Alpha** - kaminocorp/hermes-alpha: Cloud deployment template with Makefile
- **Awesome Hermes Agent** - 0xNyk/awesome-hermes-agent: Community-curated plugins, prompts, and tutorials
