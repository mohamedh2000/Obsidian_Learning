## Key Points

- **`/ce-strategy`**: Interviews you and produces a `STRATEGY.md` at repo root
  - Problem statement, approach, personas, key metrics, work tracks
  - Re-run anytime to update single sections without clobbering the rest
  - Once it exists, other skills read it (`/ce-brainstorm`, `/ce-ideate`, `/ce-plan`)
- **`/ce-product-pulse`**: Generates compact reports covering usage, performance, errors, followups
  - First run interviews to wire up data sources (MCP-preferred, read-only)
  - Saves reports to `docs/pulse-reports/`
  - Signal feeds back into strategy updates
- **`/ce-simplify-code`**: Experimental skill inspired by Claude Code's `/simplify`
  - Runs 3 parallel reviewers (reuse, quality, efficiency)
  - Works across harnesses: Codex, Copilot, Pi, and others
- **Code review tiering**: `/ce-code-review` now smarter about when to run full 7-agent review
