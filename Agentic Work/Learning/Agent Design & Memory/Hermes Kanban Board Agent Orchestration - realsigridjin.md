# Hermes Kanban Board Agent Orchestration

Hermes will soon have a kanban board similar to Cursor's one which was released today. You can just write new issues on the board then Hermes agents will pick them up, work for you, and get back to you soon. Game changer.

## Key Points

- Kanban-style task boards for agent work assignment
- Human writes issues → agents autonomously pick up and execute
- Similar UX to Cursor's agent task management
- Shifts from imperative commands to declarative work items
