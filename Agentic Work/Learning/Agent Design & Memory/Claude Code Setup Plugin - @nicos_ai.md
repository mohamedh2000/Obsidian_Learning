## Key Points

- The `claude-code-setup` plugin is an official Anthropic tool for configuring Claude Code projects.
- Analyzes your project and recommends which automations to enable: hooks, skills, MCP servers, subagents.
- Provides step-by-step configuration guidance.
- Install command: `/plugin install claude-code-setup@claude-plugins-official`
