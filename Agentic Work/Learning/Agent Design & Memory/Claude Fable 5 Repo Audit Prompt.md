## Key Points

- **Phase 1 - Discovery**: Map directory structure, identify project type, frameworks, entry points, and existing conventions
- **Phase 2 - Audit**: Evidence-based review across 8 dimensions (architecture, code quality, security, testing, performance, dependencies, DevEx, docs) with severity ratings
- **Phase 3 - Strategy**: Synthesize findings into 3-5 themes with target states, trade-offs, and measurable success criteria
- **Phase 4 - Task Plan**: Convert strategy into milestones (Safety Net → Critical Fixes → High-Leverage → Polish) with effort estimates and dependencies

## Notes

Full prompt structure:
- Emphasizes citing file:line for every finding
- Requires distinguishing facts from judgments
- Calibrates recommendations to project maturity
- Final deliverable: Executive Summary, Repo Map, Audit Report, Strategy, Task Plan, Open Questions
