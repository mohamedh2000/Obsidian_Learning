## Key Points

- Hivemind turns traces from agent runs (Claude Code, Codex, Cursor, Hermes, OpenClaw, Pi) into reusable skills
- Skills are pushed across all agents in the team, stored on your cloud storage
- Includes SkillOpt for training skills: +19.1 accuracy improvement in Claude Code, +24.8 in Codex
- Best or tied performance on all 52 setups tested
- Open source with one-line install
