> Three skill frameworks that all force the same discipline — plan and align before the agent builds — and run best in sequence: grill first, then spec-and-ship.

## Key Points

- **Superpowers (Jesse Vincent)** — a Claude Code skill framework: brainstorm requirements, lock a spec, break into small tasks, run one subagent per task in parallel, review everything against the spec. Works for code or campaigns.
- **G-Stack (Garry Tan)** — full sprint from spec to production with 23+ specialist skills; reviews through separate lenses (CEO, eng, design, devex), then QA and ship, so each lens catches what the others miss.
- **Matt Pocock's skills** — grill-first: `grill-me`/`grill-with-docs` interview you until every decision is resolved and you and the agent share vocabulary, then `to-spec`, implement with TDD, and code-review.
- Recommended order: Pocock's grilling first (so you know what you want), then Superpowers or G-Stack to plan and ship — the same order runs a launch or positioning doc as cleanly as code.
