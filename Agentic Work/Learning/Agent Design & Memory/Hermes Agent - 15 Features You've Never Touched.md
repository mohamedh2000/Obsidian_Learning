## Key Points

- **SOUL.md** - Persistent persona file read at boot; define voice, refusals, and context once
- **MEMORY.md + USER.md** - Persistent memory files indexed with FTS5 and LLM summarizer for cross-session recall
- **/insights [days]** - Analytics across all sessions: token usage, cost breakdown, stall points
- **/snapshot** - Save entire config/state before risky changes; restore with `/snapshot restore <id>`
- **/branch (/fork)** - Branch conversations like git to explore risky paths without losing context
- **/rollback** - Filesystem checkpoints for every file the agent touched
- **/btw** - Ephemeral side question using context but no tools, doesn't pollute main thread
