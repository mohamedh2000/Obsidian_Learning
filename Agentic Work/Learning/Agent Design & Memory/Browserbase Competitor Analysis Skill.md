## Key Points

- Installs with `npx skills add https://github.com/browserbase/skills --skill competitor-analysis`.
- Uses the Browserbase Search API for competitor discovery and enrichment.
- Follows a Plan -> Research -> Synthesize pattern.
- Outputs an HTML report, per-competitor Markdown files, a feature/pricing matrix, and a chronological mentions feed.
- Requires `BROWSERBASE_API_KEY` and the `browse` CLI.
