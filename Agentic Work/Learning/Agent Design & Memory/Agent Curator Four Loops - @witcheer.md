> An agent that writes its own tools needs four loops: create (save new skills when solving novel problems), measure (telemetry on use/view/patch counts), prune (auto-archive stale skills, consolidate overlaps), protect (pin skills the agent shouldn't rewrite). Hermes calls this the curator.

## Key Points
- **Create loop**: Agent saves new skills when solving novel problems
- **Measure loop**: Track telemetry on use, view, and patch counts
- **Prune loop**: Auto-archive stale skills, consolidate overlaps
- **Protect loop**: Pin skills that shouldn't be rewritten
- This pattern is called "the curator" in Hermes
