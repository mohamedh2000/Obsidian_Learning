## Key Points

- Argues static agents won't survive 2026; self-learning agents that improve with use will.
- Three learning layers: (1) Model weights — owned by labs, hardest to change; (2) Harness — loop, tools, prompts, medium difficulty; (3) Context — memory + skills, plain text and easiest to start.
- Claude Code and Codex already exercise all three layers.
- Key overlooked move: learn from your users, not just the agent's own runs.
- Every user correction is a labeled example worth more than synthetic tests — capture it and feed it back to create a compounding loop.
