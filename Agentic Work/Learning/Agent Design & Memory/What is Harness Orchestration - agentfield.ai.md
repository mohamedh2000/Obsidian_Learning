> "As the unit of intelligence moves up the stack, the model matters less."

## Key Points

- Harnesses (like Claude Code, Cursor) represent a qualitative leap beyond stateless model calls—they have agency and internal iteration
- More capable atomic units paradoxically become less predictable; systems must verify outcomes rather than control processes
- Orchestration patterns designed for model calls fail at the harness level
- Architecture quality, not raw model capability, determines system-level reliability
- Verification infrastructure accounts for ~44% of computational cost in SWE-AF builds, reflecting that checking work scales with agent autonomy
