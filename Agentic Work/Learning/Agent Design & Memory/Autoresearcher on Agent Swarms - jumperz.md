# Autoresearcher on Agent Swarms

Running an autoresearcher on your swarm is probably one of the highest leverage things you can do. Conduct 10-15 isolated experiments during off-peak hours, testing variables like prompt structure and configuration against baseline behavior, and score results against actual message history.

Run this as a separate observer agent rather than delegating to the coordinator itself. This approach enables systems to study and optimize themselves automatically through iterative experimentation.
