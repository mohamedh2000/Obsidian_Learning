## Key Points

- Presents DeepThink as a Hermes-style skill for slowing agents down before expensive architecture, security, pricing, debugging, or launch decisions.
- The workflow restates the real decision, separates facts from assumptions, generates options, red-teams tradeoffs, and recommends the next safe step.
- The goal is not longer answers; it is a grounded recommendation with evidence, reversibility, timing fit, and confidence.
- Useful pattern for agent systems that need explicit judgment gates before tool use or irreversible changes.
