# Perplexity Sandbox - Code Execution for AI Agents

> Perplexity's Sandbox tool enables AI agents to execute code in isolated containers during API requests for computations, data processing, and artifact generation.

## Key Points

- Preview feature in Perplexity's Agent API allowing code execution during requests
- Runs in isolated containerized environments (Python and other languages)
- Capabilities: web search, calculations, data cleaning, structured artifact generation (CSV, JSON, reports)
- Supports background processing for long-running tasks with polling
- Pricing: $0.03 per sandbox session (up to 20 min) + standard token charges
- Simple integration: add `{"type": "sandbox"}` to tools array
