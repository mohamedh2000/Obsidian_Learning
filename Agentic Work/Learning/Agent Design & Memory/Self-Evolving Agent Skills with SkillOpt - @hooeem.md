## Key Points

- SkillOpt is a text-space optimizer from Microsoft that treats skill documents as trainable artifacts
- Unlike fine-tuning (changes weights) or prompting (one-shot guess), SkillOpt changes a persistent skill document
- The loop mirrors neural network training: frozen target model → optimizer model proposes edits → bounded edit budget → validation gate
- "Textual learning rate" caps how much a skill can change per step
- Best for tasks with verifiable outputs: extraction, classification, structured generation, QA with reference answers, code that runs or doesn't
- Not suited for tasks where "correct" doesn't exist
