# DSPy - Declarative AI Programming Framework

> Express tasks as structured signatures, not prompts, to produce maintainable, modular, and optimizable AI programs.

## Core Concepts

| Concept | Description |
|---------|-------------|
| **Signatures** | Typed input/output task definitions, independent of implementation |
| **Modules** | Interchangeable execution strategies (prediction, reasoning chains, tool use, ensembles) |
| **Optimizers** | Automatic prompt and demonstration tuning without manual iteration |

## Key Points

- **Decouples task specification from execution** — swap strategies without rewriting definitions
- **Automatic optimization** against metrics via built-in compilation
- **Multimodal support**: images, code, audio alongside text
- **Python ≥3.10**, MIT licensed
- **Production deployments**: Databricks, Shopify, Dropbox

## Problem Solved

Traditional prompting creates brittle, hard-to-maintain systems. DSPy provides systematic optimization and modular composition at scale.
