# What Is an Agent - Agentic Loop Components

> An agent can be viewed as an LLM running inside an agentic loop with instructions, tools, an environment, and termination conditions.

## Key Points

- The core loop combines an LLM backbone, instructions, tools, and a stateful environment that returns feedback after tool calls.
- Agent harnesses manage orchestration details such as tool-call representation, context management, memory, and termination checks like maximum steps, tests, or termination tokens.
