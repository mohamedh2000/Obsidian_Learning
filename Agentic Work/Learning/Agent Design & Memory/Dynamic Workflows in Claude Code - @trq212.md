## Key Points

- **Dynamic workflows** allow Claude to create custom harnesses on the fly for specific tasks
- While the default Claude Code harness is built for coding, custom harnesses are needed for: Research, security analysis, agent teams, Code Review
- Workflows execute JavaScript files with special functions to spawn and coordinate subagents
- Workflows can choose which models agents use and whether they run in isolated worktrees
- If interrupted, resuming the session allows workflows to pick up where they left off

## Example Workflow Prompts

- "This test fails 1 in 50 runs. Set up a workflow to reproduce it, form theories and adversarially test them in worktrees"
- "Go through my last 50 sessions and mine them for corrections I keep making and turn recurring ones into CLAUDE.md rules"
- "Dig through #incidents in Slack for the past six months and find recurring root causes"
- "Take my business plan and run agents tearing it apart from investor's, customer's, and competitor's perspectives"
- "Here's 80 resumes, rank them and double-check the top ten"
- "Go through my blog post draft and verify every technical claim against the codebase"
