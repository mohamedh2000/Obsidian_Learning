## Key Points

- Two design systems: Editorial (magazine-inspired, narrative) and Swiss International (grid-based, data-focused)
- 28 layout templates (16 Editorial, 12 Swiss), 10 theme presets, 3 canvas dimensions
- Single-file HTML-to-PNG rendering via Playwright — no build pipeline required
- Automated layout validator catches overflow, typography violations, composition issues
- Image sourcing waterfall: user uploads → AI-generated → Unsplash/Pexels/Wallhaven
- WebGL ink-flow backgrounds and screenshot beautification tools
- Supports Chinese and English typography
- Philosophy: restraint over loudness, structured hierarchy over decoration
