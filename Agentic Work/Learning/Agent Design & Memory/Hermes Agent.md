> Hermes Agent is Nous Research's self-improving open-source agent with built-in memory, skill creation, and multi-platform runtime support.

## Key Points

- The repo centers on a closed learning loop: the agent can create skills from experience, improve them during use, persist knowledge, and search prior conversations.
- Hermes exposes both a terminal UI and messaging-gateway workflows across Telegram, Discord, Slack, WhatsApp, Signal, and more.
- The runtime story is broader than laptop-only agents, with support for local, Docker, SSH, Daytona, Singularity, and Modal backends.
