## Key Points

- Hermes computer use is described as moving beyond macOS to Windows and Linux via `cua-driver` running as an MCP server.
- The workflow uses screenshots with numbered elements so the agent can click, type, scroll, submit, and read results while the user's cursor and focus stay undisturbed.
- Suggested use cases include summarizing desktop-only email, filling web forms with no API, navigating Mail/browser/Finder, and extracting data from GUI-only apps.
- Safety notes include approval gates for destructive actions, blocked dangerous command patterns, no permission-dialog clicking, and no password typing.
