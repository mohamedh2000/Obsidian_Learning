## Key Points

- Covers the full agentic AI stack: transformer foundations, GPU systems, fine-tuning, compression, inference, alignment, reasoning, and deployment.
- Treats RLHF, PPO, DPO variants, GRPO, reward modeling, and test-time scaling as core prerequisites for reasoning-capable systems.
- Dedicates the second half to agentic systems: trajectory-based RL, RAG, agentic RAG, memory types, harness design, context management, and design patterns.
- Includes coordination layers such as MCP, agent skills, tool use, A2A communication, and centralized, decentralized, and hierarchical multi-agent topologies.
- Useful as a roadmap for connecting research concepts to implementation details, evaluations, and production operations.
