# Autoreason for On-Page SEO

> Autoreason fixes generic LLM rewrites with adversarial isolation — every role is a fresh agent that can't see what the others wrote, so output doesn't collapse into the same generic advice.

## Key Points

- **Adversarial isolation**: Each role (incumbent, strawman, author B, synthesizer, judge panel) is a fresh agent that can't see others' outputs
- **Strawman role**: Sees only page + keyword + SERP competitors + ICP data from sales calls, writes critiques without rewriting
- **Judge panel**: 3 fresh agents do blind ranked-choice vote using Borda count, convergence at streak=2
- **Knowledge layer grounding**: GSC data, Ahrefs/Moz competitor data, GA4 conversions, sales call transcripts, top-performing pages
- **Works for**: service pages, free tool pages, programmatic SEO templates, GEO/AI overviews
