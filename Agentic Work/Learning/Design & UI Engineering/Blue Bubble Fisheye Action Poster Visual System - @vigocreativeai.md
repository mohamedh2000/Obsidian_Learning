## Key Points

### Visual DNA System

A unified visual identity for action posters that looks like a "city flash brand":

- **White background** with giant blue bubble typography
- **Low-angle 16:9 fisheye photography**
- **Exaggerated foreground perspective** + motion blur
- **Red hand-drawn circle** to lock key prop

### Modularity

By only swapping scene/action/prop, the system scales across:
- Rooftop plant delivery
- Solar field runner
- Gelato counter flip
- Transit bag launch

### Implementation

JSON skeleton provided for systematic reproduction of the visual language.
