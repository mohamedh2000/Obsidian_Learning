## Key Points

- Encodes Swiss/International Typographic Style constraints: modular columns and rows, baseline grids, restrained typography, white space, asymmetry, and a limited black/white/red palette.
- Emphasizes web implementation details that make the grid load-bearing: shared CSS variables, overlay guides in the same content box, subgrid bands, and baseline-locked spacing.
- Includes workflow guidance plus scripts for generating a grid scaffold and verifying column adherence, overlay alignment, baseline rhythm, and optical type alignment.
