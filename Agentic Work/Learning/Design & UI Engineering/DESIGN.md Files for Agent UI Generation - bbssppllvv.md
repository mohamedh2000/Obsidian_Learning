# DESIGN.md Files for Agent UI Generation

Agents make ugly UIs because they've never seen good design. This project fixes that with 2,000 DESIGN.md files from the world's best products, structured for a model to read and learn. Colors, type, spacing, layouts and more. Free at styles.refero.design.

## Key Points

- Agents lack design training data in structured form
- DESIGN.md files provide machine-readable design systems
- Covers: colors, typography, spacing, layouts
- Sourced from world-class product designs
- Free resource for improving agent-generated UIs
