2. **CSS `writing-mode: vertical-rl`** = sidebar navigation rotates 90 degrees
3. **Framer scroll animations** = character entrances, zero GSAP needed

5. **Framer variables** = color theme swaps per chapter in one click

## Techniques

- Leveraging Framer's native scroll animations instead of external libraries
