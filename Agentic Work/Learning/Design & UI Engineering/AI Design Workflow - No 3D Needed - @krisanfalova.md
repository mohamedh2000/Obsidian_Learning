## Key Points
- Demonstrates that complex-looking 3D effects can be achieved without actual 3D software
- Workflow: Midjourney (base + static assets) → Seedream (360° rotation video) → Figma (structure/typography) → Jitter (animation) → CapCut (overlay with alpha channel)
- "1st-grade level parallax" — the illusion of depth comes from basic parallax techniques, not real 3D rendering
- PNG sequence from video with alpha channel is the key technique for overlaying rotating elements

### Tool Stack Breakdown
- **Midjourney**: Base background generation and static cookie asset
- **Seedream**: 360-degree rotation video generation (better at rotation than MJ)
- **Figma**: Structure and typography composition
- **Jitter**: Animation of the assembled design
- **CapCut**: Video overlay with alpha channel (could use After Effects but simpler)

### Design Pattern Context
This workflow exemplifies the "fake it till you make it" approach to modern design — combining generative AI tools strategically to achieve results that would traditionally require specialized 3D skills. The key insight is that parallax + alpha channel compositing creates convincing depth without actual 3D modeling.
