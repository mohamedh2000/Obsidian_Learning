## Key Points

- **Input**: Upload a logo
- **Prime Directive**: Every element extracted directly from logo — nothing generic or templated
- **Format**: Vertical 4:5, multi-column grid, layered dense layout
- **Sections**:
  - Brand header (name, statement, 3 soul descriptors)
  - Color system (primary, secondary, accent palettes with HEX codes)
  - Typography system (headline, subheadline, body hierarchy)
  - Visual language (image style, lighting, textures, mood tiles)
  - Brand applications (packaging, website hero, mobile app, social media, business card, billboard)
  - Design system (buttons, cards, inputs, nav, spacing)
  - Iconography (6-10 icons matching logo's visual grammar)
