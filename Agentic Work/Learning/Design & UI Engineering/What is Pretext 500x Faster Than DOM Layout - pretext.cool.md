# What is Pretext — The JavaScript Library That's 500x Faster Than DOM Layout

> Pretext is a pure JavaScript/TypeScript library for multiline text measurement and layout without touching the DOM, enabling dramatically faster text rendering via a canvas-based font engine.

## Key Points

- DOM-free text measurement and layout library
- ~500x faster than DOM layout in benchmarks
- API: prepare / layout / layoutWithLines
- Global typography: CJK, Arabic, Hebrew
- Suitable for text games, animations, typographic experiments
