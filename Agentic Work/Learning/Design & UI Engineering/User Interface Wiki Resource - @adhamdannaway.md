## Key Points
- UserInterface.wiki is a curated knowledge base specifically focused on UI design patterns rather than general design inspiration
- Created by Raphael Salaja as a continuously growing resource, implying active maintenance and updates
- Content structure includes articles (long-form explanations), patterns (reusable solutions), and best practices (guidelines)
- Targets both designers and developers who need to understand the "why" behind interface decisions, not just the "what"

### Why This Resource Matters
Unlike inspiration galleries that show finished designs, a wiki format provides context, rationale, and implementation guidance. This fills a gap between "look at this pretty UI" and "here's the design system documentation" — it's the missing educational layer that helps practitioners internalize principles rather than just copy patterns.
