### Why This Matters
Pure CSS animations offer performance advantages over JavaScript-driven motion: they run on the compositor thread, avoiding layout thrashing and main-thread blocking. This experiment shows how far CSS keyframes, transforms, and timing functions can be pushed when paired with strong visual design.
