## Key Points
- **Variant UI** (@variantui) allows importing existing websites as design references to guide AI-generated outputs
- The import feature solves the "cold start" problem of AI design tools where users struggle to articulate their desired aesthetic
- After importing a reference site, users can iterate on three axes: **style**, **layout**, and **color**—each adjustable independently
- This approach bridges the gap between "I know it when I see it" design intuition and structured AI prompting

### Workflow Pattern
1. **Import** — Paste URL of a site whose vibe you want
2. **Explore style** — Adjust typography, spacing, visual weight
3. **Explore layout** — Modify grid, component arrangement, density
4. **Explore color** — Shift palette while preserving structure

### Why It Matters
Most AI design tools force users to describe aesthetics in words. Variant UI flips this: show, don't tell. Reference-based generation is more intuitive for visual thinkers.
