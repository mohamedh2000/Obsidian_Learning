## Key Points

- **[siteinspire.com](https://www.siteinspire.com)** — curated web design showcase
- **[typewolf.com](https://www.typewolf.com)** — typography-focused design inspiration
- **[siteofsites.co](https://www.siteofsites.co)** — site inspiration directory
- **[maxibestof.one](https://maxibestof.one)** — curated best-of collections
- **[footer.design](https://www.footer.design)** — footer design patterns

- **[awwwards.com](https://www.awwwards.com)** — web design awards and showcases

### Why This List Matters

Each site serves a distinct need:
- **siteinspire** for overall aesthetic direction
- **typewolf** for font pairing and typography decisions
- **footer.design** for specific component patterns
- **awwwards/thefwa** for cutting-edge, award-winning work
