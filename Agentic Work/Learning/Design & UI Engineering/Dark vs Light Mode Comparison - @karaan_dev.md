### Why Dark Mode Often "Feels" Better
Dark mode advantages in UI perception:
- **Higher contrast for colorful elements**: Gradients, accent colors, and imagery pop more against dark backgrounds
- **Perceived modernity**: Dark interfaces signal "tech-forward" aesthetic (dev tools, creative apps)
- **Reduced visual noise**: Dark backgrounds recede, letting content and UI elements take center stage
- **Eye comfort in low-light**: Users increasingly browse at night — dark mode is more comfortable

### When Light Mode Wins
Light mode is preferable for:
- Long-form reading (better readability at smaller sizes)
- Print-adjacent contexts (documents, forms)
- High-ambient-light environments
- Trust signals in finance/healthcare (light = clean, transparent)

### Design Takeaway
The answer is "both" — mature design systems support theme switching. But for showcasing UI work on social media, dark mode often photographs better.
