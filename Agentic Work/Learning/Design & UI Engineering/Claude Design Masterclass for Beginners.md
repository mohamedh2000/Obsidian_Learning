## Key Points

- Claude Design is a conversational design tool powered by Claude Opus 4.7
- Reads your brand: imports codebase and design files, inherits colors, typography, patterns
- Understands context: upload reference images, documents, use web capture tool
- Multiple export options: PDF, PPTX, HTML, Canva, or handoff bundle to Claude Code
- Use cases: landing pages (15 min), pitch decks (20 min), product prototypes, social graphics, one-pagers, interactive prototypes with voice/video/3D/AI
