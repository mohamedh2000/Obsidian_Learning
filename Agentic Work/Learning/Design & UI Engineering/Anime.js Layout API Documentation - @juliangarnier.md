### What Layout APIs Enable
Layout animation APIs automatically handle:
- Position transitions when elements reorder (list shuffling)
- Size transitions when content changes
- FLIP-based optimizations (First, Last, Invert, Play)
- Cross-component coordination for shared element transitions

### Library Context
Julian Garnier is the creator of Anime.js, one of the most popular JavaScript animation libraries. The addition of a Layout API brings Anime.js closer to feature parity with Framer Motion while maintaining its vanilla JS, framework-agnostic approach.
