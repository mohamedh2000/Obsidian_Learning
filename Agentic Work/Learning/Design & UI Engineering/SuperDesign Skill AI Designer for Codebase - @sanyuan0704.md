## Key Points
- Solves the "vibe coder" problem of exploring different UI styles without easy back-and-forth between designs in coding agents
- The skill generates multiple production-ready UI variations simultaneously on an infinite canvas
- Workflow: explore designs → compare variations → iterate → pick favorite → ship production code
- Install via single command: `npx skills add superdesigndev/superdesign-skill`
- Demonstrated on OpenClaw dashboard refactor — shows practical multi-style exploration
- GitHub repo: github.com/superdesigndev/superdesign-skill

### How It Works

The skill bridges the gap between AI code generation and design exploration:

1. **Current UI Reproduction** — Reads your codebase and reproduces existing UI pixel-perfect as starting point
2. **Infinite Canvas Generation** — Creates multiple design variations simultaneously for visual comparison
3. **Browser Preview** — Opens variations directly in browser for real-time evaluation
4. **Production-Ready Output** — Selected design exports as actual code, not mockups
