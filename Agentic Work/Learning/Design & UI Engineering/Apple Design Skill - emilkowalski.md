## Key Points

- Distills Apple's WWDC design talks (chiefly *Designing Fluid Interfaces*, WWDC 2018) into web-platform terms — CSS, Pointer Events, `requestAnimationFrame`, and spring libraries like Motion/Framer Motion.
- Through-line: an interface feels alive when motion starts from the current on-screen value, inherits the user's velocity, projects momentum forward, and can be grabbed and reversed at any instant.
- Springs are the core tool because they are inherently interruptible and velocity-aware.
- Response first: respond on pointer-down not release, kill every latency on the input path, and keep feedback continuous *during* the interaction (1:1 with the pointer), not just at the end.
- Frames design around four human needs: safety/predictability, understanding, achievement, and joy.
