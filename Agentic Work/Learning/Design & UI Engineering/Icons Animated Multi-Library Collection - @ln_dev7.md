## Key Points
- **Multi-Library Support**: Unlike single-library animated icon sets, this supports three major icon families — Huge Icons (4000+ free icons), Tabler Icons (MIT-licensed SVGs), and Phosphor Icons (flexible interface icons)
- **shadcn CLI Installation**: Icons are installable via shadcn CLI, meaning they drop into existing shadcn/ui projects as first-class components — no manual setup required
- **TypeScript-First**: 97% TypeScript codebase ensures strong typing for icon props, making IDE autocomplete and type checking work properly
- **Lucide-Animated Lineage**: Credits and builds on the original lucide-animated.com project by @pqoqubbw — extends the concept to additional icon families rather than reinventing the wheel

### Supported Icon Libraries
| Library | Description |
|---------|-------------|
| Huge Icons | 4000+ free icons |
| Tabler Icons | MIT-licensed SVG icons |
