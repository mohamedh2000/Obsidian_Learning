> "Build each section as a scene not a page. Write copy like a movie not a product page."

## Key Points

### 1. Tell a Story Through Vertical Scroll
- Design the page as a narrative journey, not a static layout
- Each scroll position reveals the next chapter

### 2. Use Realtime 3D Assets That Animate on Scroll
- 3D elements that respond to scroll position create depth and engagement
- Animation tied to scroll progress keeps user in control

### 3. Transform Sequences
- Let genetic code transform into seeds → plants → harvests
- Use visual metaphors that evolve as user scrolls

### 4. Pure Black Color Palette
- Maximum drama through contrast
- Black background makes 3D assets and typography pop

### 5. Build Sections as Scenes, Not Pages
- Each section should feel like a cinematic moment
- Transition between scenes, not between blocks of content

### 6. Write Copy Like a Movie
- Product pages should have narrative tension
- Avoid corporate speak — use cinematic pacing and language
