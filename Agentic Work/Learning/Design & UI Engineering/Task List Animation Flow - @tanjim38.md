### Animation Patterns for Task Lists
Common task list animation techniques include:
- **Staggered entry**: Items cascade in with delay offsets
- **Completion celebration**: Checkmark bounce, strikethrough swipe, confetti
- **Reorder transitions**: Drag-and-drop with spring physics
- **Delete/archive**: Slide-out with height collapse
- **Empty state reveal**: Fade in illustration when list clears

### Why This Matters
Task lists are among the most common UI patterns. Elevating them with thoughtful animation differentiates products in crowded SaaS markets and increases perceived quality without changing core functionality.
