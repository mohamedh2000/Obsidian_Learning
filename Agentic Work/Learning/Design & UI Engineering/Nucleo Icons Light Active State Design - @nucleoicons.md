## Key Points

- Demonstrates strategic use of light effects to indicate active/selected states in UI
- Features duotone icon style — icons rendered with two color values for depth and visual hierarchy
- Showcases work by designer Fabian as an exemplar of effective icon state design
- Active states communicate interactivity and current selection through visual affordances like glow, fill changes, or brightness shifts

### Why Light Matters for Active States

Light effects (glows, highlights, increased saturation) naturally draw attention and signal "on" or "selected" states. This leverages real-world mental models where illuminated objects appear more prominent. Duotone icons work well here because the second tone can shift or intensify to communicate state changes.
