## Key Points
- **Three.js** — 360-degree rotatable product display without external plugins
- **WebGL PointLight** — UVC glow effect that reacts to scroll position for dynamic lighting
- **CSS scroll-snap** — "Buttery infinite horizontal product scroll" for smooth carousel-like navigation
- **GSAP ScrollTrigger** — Product pins in place while accompanying copy scrolls alongside
- **Lottie via lottie-web** — After Effects animations play directly in browser
