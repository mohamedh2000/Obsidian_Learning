## Key Points
- **Design as communication**: The ultimate test of UI clarity — can users understand the product without additional explanation?
- **Show don't tell**: Visual communication should convey value proposition, not require accompanying copy
- **Self-documenting interfaces**: Clear design eliminates the need for onboarding, tooltips, or explainer content
- **Design confidence signal**: Posting this claim implies the accompanying visual strongly demonstrates the principle

### The Clarity Test
A "clear" design passes these checks:
1. **Purpose is obvious**: User knows what the product does within 3 seconds
2. **Hierarchy guides attention**: Primary action is unmistakably prominent
3. **Affordances are clear**: Clickable things look clickable, inputs look editable
4. **Minimal cognitive load**: No unnecessary decisions or parsing required
5. **Visual language is consistent**: Patterns repeat predictably

### Why This Matters
Most products fail the clarity test:
- Marketing landing pages that require reading paragraphs to understand the product
- Apps with "innovative" UI patterns that confuse users
- Dashboards with undifferentiated information density

When design is truly clear, it unlocks:
- Higher conversion (users self-qualify faster)
- Lower support burden (fewer "how do I..." questions)
- Faster time-to-value (users accomplish goals immediately)

### Design Philosophy
Steve Krug's "Don't Make Me Think" distilled: every moment of confusion is a moment the user might leave. Clear design respects user attention.
