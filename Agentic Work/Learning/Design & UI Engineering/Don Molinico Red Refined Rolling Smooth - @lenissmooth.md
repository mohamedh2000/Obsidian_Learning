## Key Points

- **Red Color Palette**: The site uses a bold red theme ("Red, refined, and rolling smooth") for an olive oil brand — unusual for the industry, typically dominated by greens and golds
- **Smooth Scroll Experience**: As a Lenis showcase, the site demonstrates the library's capabilities for creating fluid, elegant scroll interactions
