## Key Points

- CSS `blend-mode` enables text over photography in one line
- GSAP `ScrollTrigger` pins hero while content scrolls over it
- `Splitting.js` animates title letter by letter on load
- Video `autoplay muted` makes content feel alive without user interaction
- CSS `clamp()` scales typography mobile to desktop with zero media queries
- `linear-gradient` overlay ensures text readability at any screen brightness
