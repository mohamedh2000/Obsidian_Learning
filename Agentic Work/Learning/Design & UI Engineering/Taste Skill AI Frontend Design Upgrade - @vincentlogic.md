## Key Points

- **Problem identified**: AI-written frontend looks cheap — generic templates, default colors, system font vibes
- **Taste Skill solution**: github.com/leoninx/taste-skill — transforms AI frontend output to look human-designed
- **Universal compatibility**: Works with Cursor, Claude Code, v0, Lovable — all major AI coding tools
- **High adoption**: ~20k GitHub stars — significant community validation
- **One command install**: Low friction to add to existing workflows

### Why This Matters

The "AI slop" aesthetic is a real problem — generated code often has telltale signs (Tailwind defaults, generic layouts, placeholder-ish colors). Taste Skill addresses this at the skill/prompt layer, injecting design sensibility into the generation process. This is a proxy for a larger trend: skills that upgrade AI output quality.
