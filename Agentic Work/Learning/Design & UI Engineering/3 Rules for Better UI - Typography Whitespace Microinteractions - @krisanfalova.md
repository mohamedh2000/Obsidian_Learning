## Key Points

### 1. Consistent Typographic Hierarchy
- Stop using 14 different font sizes
- Establish a clear type scale and stick to it
- Consistency creates visual rhythm and reduces cognitive overhead

### 2. Intentional Whitespace
- Let your interface breathe
- Clutter = cognitive load
- Whitespace isn't wasted space — it's a design tool for focus and hierarchy

### 3. High-Contrast Micro-Interactions
- Users want to FEEL that a button was clicked
- Feedback should be immediate and obvious
- Contrast in interactions (visual, haptic, or motion) confirms user actions

### Design Pattern Context
These three rules address the most common amateur UI mistakes: typography chaos, information overload, and dead-feeling interfaces. Each rule targets a different sensory dimension of the user experience — visual consistency (typography), spatial breathing room (whitespace), and tactile feedback (microinteractions).
