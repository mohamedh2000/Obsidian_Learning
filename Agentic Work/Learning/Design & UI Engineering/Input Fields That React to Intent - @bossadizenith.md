### What "Reacting to Intent" Might Mean
Intent signals go beyond traditional input events:
- **Hover proximity**: Subtle glow or label shift as cursor approaches
- **Selection anticipation**: Dropdown options begin loading on hover, not on click
- **Error prevention**: Visual warnings before submission based on partial input patterns
- **Context awareness**: Field adapts based on what user typed in previous fields
- **Gesture direction**: Mobile inputs that sense swipe intent vs. tap

### Why This Matters
Form UX is often an afterthought, yet forms are where users provide value to applications. Intent-reactive patterns reduce cognitive friction and make interfaces feel intelligent—key differentiator for premium product feel.
