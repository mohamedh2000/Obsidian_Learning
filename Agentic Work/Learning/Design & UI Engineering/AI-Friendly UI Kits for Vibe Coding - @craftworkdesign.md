## Key Points
- **Curation focus**: "AI-friendly" means these kits work well with code generation — clean APIs, consistent patterns, good documentation
- **10 libraries listed**: Mix of established (Tremor, Tailwind-based) and emerging (MagicUI, Aceternity) options
- **Vibe coding**: The trend of using AI assistants for rapid UI prototyping — these kits reduce friction in that workflow
- **Central directory**: Full catalog at craftwork.design/curated/websites

### Why "AI-Friendly" Matters
AI coding assistants perform better with:
- Consistent naming conventions
- Well-documented component APIs
- Copy-paste-ready code snippets
- Predictable composition patterns

These kits are designed (or have evolved) to meet those criteria.
