### Why Animation Matters
The "even better animated" framing highlights a common design workflow: start with static compositions, then layer in motion. Animation transforms flat UI into living interfaces through:
- Micro-interactions (hover states, button presses)
- Transitions (page changes, modal opens)
- Feedback (loading states, success confirmations)
- Storytelling (onboarding flows, feature reveals)
