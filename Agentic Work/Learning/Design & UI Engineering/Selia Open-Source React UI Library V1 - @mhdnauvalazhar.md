## Key Points

- **57+ components** ranging from basic (Alert, Badge, Button) to complex (Dialog, Form, Table, Tabs, Tooltip)
- Built on [[Base UI]] (headless, unstyled primitives from MUI team) and [[Tailwind CSS]] for styling
- Primary goal is **visual cohesion** — components designed to work seamlessly together without constant tweaking
- Includes **24+ pre-built Blocks** (layout templates like dashboards, hero sections, pricing pages)
- Can be used as-is or as a starting point for building custom design systems
- TypeScript-first (85.5% of codebase), with MIT license

### Why This Matters

Opinionated component libraries reduce decision fatigue — instead of assembling a design system from scratch, Selia provides a cohesive visual language out of the box. Building on Base UI means accessibility and keyboard navigation are handled, while Tailwind enables rapid customization.
