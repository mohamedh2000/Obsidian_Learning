## Key Points
- Drag-and-drop form building interface with live preview — see exactly what you're building in real time
- Exports clean, typed React components with Tailwind CSS styling — production-ready, not prototypes
- Direct shadcn/ui integration means components match your existing design system out of the box
- Zero setup required — no configuration, just start building
- 99.6% TypeScript codebase; MIT licensed; latest release v1.7.5 (Nov 2025)

### Why It Matters
Form building is tedious boilerplate. This tool lets designers or non-coders create forms visually, then exports idiomatic React code that developers don't need to rewrite. Bridges design-dev handoff for form-heavy applications.

### Use Cases
- Rapid prototyping of multi-step forms
- Internal tools where form creation is frequent
- Design-to-code workflows where non-devs define form structure
