## Key Points

- References a GitHub skill for image generation prompting: `github.com/Leonxlnx/taste-skill/blob/main/skills/imagegen-frontend-web/SKILL.md`
- Requests 8 distinct images, one per section, for a creative AI company website
- Emphasizes originality, playfulness, and thoughtful text integration in visuals
- Explicitly rejects standard layouts (text-left, image-right) in favor of experimental, varied compositions
- Calls for horizontal images, fullscreen sections, full background imagery, and minimal sections with motion/animation feel
- Requires full background images or strong color compositions — no plain white sections, light mode only
- Seeks consistency across sections while keeping each distinct — "crazy creative, thoughtful, and visually impressive"

### The Prompt

The full prompt demonstrates how to art-direct AI image generation for high-end web design:
- Define the brand context (creative AI research company)
- Set the quality bar (Awwwards SOTD-level)
- Specify layout variety (experimental, not standard)
- Call out technical requirements (8 separate images, not combined)
- Balance consistency with distinctiveness
