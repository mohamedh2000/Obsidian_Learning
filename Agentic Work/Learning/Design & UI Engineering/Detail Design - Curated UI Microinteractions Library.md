> Detail is where craft lives — a curated reference platform showcasing small design decisions that shape better interfaces.

**Topics:** [[UI & Design Engineering]], [[Design Inspiration]], [[Microinteractions]]

## Key Points
- **Curated Microinteraction Library**: Collection of small UI details — animation timing, hover states, copy choices, responsive behavior — that separate good interfaces from great ones
- **Filterable by Type**: Categories include Design, Motion, Easter Egg, and more — enables targeted browsing for specific interaction patterns
- **Video/Visual Demonstrations**: Each detail includes visual proof — not just descriptions, but actual recordings of the interaction in context
- **Bi-Weekly Newsletter**: Regular updates with new discoveries — positions as ongoing learning resource, not static archive
- **Community Ecosystem**: Discord server, X/Twitter presence, and submission system — indicates active community curation beyond solo effort

### Why This Matters
"Why does this product feel premium?" is often answered by accumulated microinteractions — hover states that ease correctly, loading spinners that respect attention, error messages that read human. Detail.design makes these invisible decisions visible and learnable.

### Use Cases
- **Design Review**: Reference when auditing your own UI for polish opportunities
- **Onboarding Designers**: Show junior designers what "attention to detail" actually means with concrete examples
- **Specification**: Link specific Detail entries in design specs to communicate exact interaction expectations
- **Inspiration Mining**: Browse before starting new component work to steal best-in-class patterns
