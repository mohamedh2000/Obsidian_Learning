## Key Points
- **Zero dependencies**: Presentations are single HTML files with embedded CSS/JavaScript — no npm, no build process, just one file
- **Visual style discovery**: Shows 3 preview designs for comparison instead of asking users to describe preferences verbally
- **PowerPoint conversion**: Extracts text, images, and notes from existing PPTX files while preserving assets
- **12 curated themes**: Dark (Bold Signal, Electric Studio, Creative Voltage, Dark Botanical), Light (Notebook Tabs, Pastel Geometry, Split Pastel, Vintage Editorial), Specialty (Neon Cyber, Terminal Green, Swiss Modern, Paper & Ink)

### Technology Stack
- **Languages**: Shell (75.7%), CSS (14.1%), Python (10.2%)
- **Dependencies**: Claude Code CLI, Python with `python-pptx`, Node.js, Vercel (optional, for deployment)
- **Export**: Playwright for PDF conversion

### Workflow
```
User prompt       →    3 style previews    →    Selection    →    Full presentation
                       (visual discovery)
```

### Use Cases
1. Converting existing PowerPoint decks to web-based presentations
2. Creating presentations from scratch with consistent, professional styling
3. Rapid prototyping of slide decks for talks/pitches
