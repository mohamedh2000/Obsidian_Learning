## Key Points

- **Web design:** [curated.design](http://curated.design) — hand-picked web design showcase
- **Landing pages:** [onepagelove.com](http://onepagelove.com) — single-page and landing page gallery
- **Design systems:** [component.gallery](http://component.gallery) — component and design system reference
- **Animation:** [appmotion.design](http://appmotion.design) — motion design and UI animation examples
- **Apps:** [mobbin.com](http://mobbin.com) — mobile app UI patterns and screenshots
- **Brands:** [rebrand.gallery](http://rebrand.gallery) — brand identity and rebranding case studies

### Why This List Matters

Each site serves a distinct need in the design process:
- **curated.design** for overall web aesthetic direction
- **onepagelove** for conversion-focused landing page patterns
- **component.gallery** for systematic UI component reference
- **appmotion.design** for learning animation timing and easing
- **mobbin** for mobile-specific UI research
- **rebrand.gallery** for brand evolution case studies
