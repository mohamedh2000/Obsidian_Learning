## Key Points
- **AI tool theming**: Login screen designed specifically for an AI/data scraping context — likely dark mode, technical aesthetic matching the product domain
- **Specialized form design**: Authentication UX for developer/technical tools requires balancing security cues with approachability
- **Andrea Montini portfolio piece**: Part of @andreamontini's UI design showcase — see also [[Micro-interactions on Onboarding Design - @andreamontini]] for related onboarding work
- **Data product branding**: Login screens for data/scraping tools often emphasize trustworthiness (data security) and capability (technical sophistication)

### Login Screen Design Patterns for Technical Tools
1. **Dark mode default**: Signals developer-friendly, reduces eye strain for power users
2. **Minimal fields**: Email/password or SSO buttons — no unnecessary friction
3. **Brand reinforcement**: Logo, tagline, or product illustration in unused space
4. **Security indicators**: HTTPS badges, 2FA availability, password strength meters
5. **Error states**: Clear validation messaging without exposing security info
