## Key Points

- **Spline for 3D**: Interactive 3D organic shapes with zero modeling needed — drag-and-drop 3D in web projects
- **Next.js App Router**: Trend sections preload making transitions instant — leveraging RSC for perceived performance
- **WebGL ShaderMaterial**: Iridescent color shift that reacts to mouse position — creates depth and interactivity
- **GSAP ScrollTrigger**: Headline pins while 3D object floats independently — sophisticated scroll choreography
- **CSS clamp()**: Oversized display text scales every screen automatically — fluid typography without media queries

### Why This Matters

This stack represents the current gold standard for high-impact marketing sites: Spline handles the 3D complexity, Next.js handles the performance, GSAP handles the scroll choreography, and CSS clamp() handles responsive scaling. Each tool removes a traditional bottleneck (3D modeling, server rendering, scroll math, breakpoint management).
