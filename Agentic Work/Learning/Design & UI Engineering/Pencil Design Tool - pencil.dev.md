> Pencil brings design directly into your IDE — "Design on Canvas, Land in Code." A Next.js-based design tool that aims to fundamentally increase engineering speed by eliminating the design → code handoff.

## Key Points
- **IDE-Native Design**: Unlike Figma/Sketch which run separately, Pencil integrates directly into developer IDEs — design and code in the same environment
- **Canvas-to-Code Pipeline**: The tagline "Design on Canvas, Land in Code" emphasizes direct code generation from visual designs, not export → import workflows
- **Next.js Foundation**: Built on Next.js, suggesting a web-first architecture and potentially Vercel deployment optimization
- **Workflow Unification**: Addresses the disconnect between design tools (Figma) and development tools (VS Code) — one environment for both

### Value Proposition
```
Traditional Workflow:
┌────────┐    ┌────────┐    ┌────────┐
│ Figma  │ → │ Export │ → │ IDE    │
│ Design │    │ Assets │    │ Code   │
└────────┘    └────────┘    └────────┘
   (Context switches, handoff friction)

Pencil Workflow:
┌──────────────────────────────────┐
│        Pencil in IDE             │
│  Canvas Design ↔ Code Generation │
└──────────────────────────────────┘
   (Single context, no handoff)
```
