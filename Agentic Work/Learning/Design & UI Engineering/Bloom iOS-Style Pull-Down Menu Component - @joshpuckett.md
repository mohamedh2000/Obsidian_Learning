## Key Points
- **Bloom**: An iOS-inspired pull-down menu component for web, providing morphing menu animations from button to expanded state
- **Timeboxed build**: Shipped in a single evening—demonstrates rapid prototyping of polished UI components
- **Tech stack**: React + Framer Motion + Tailwind CSS (MIT licensed, `npm install bloom-menu framer-motion`)
- **Configurable**: Supports multiple directions (top, bottom, left, right), anchor positioning, nested submenus, and hover highlighting

### How It Works
Bloom provides smooth animations between button and menu states. The component morphs from a compact trigger into an expanded menu with configurable dimensions. Key features include:
- Direction-aware positioning
- Nested submenu support
- Customizable open/close behavior
- Hover state highlighting

### Learning Resource
Josh recommends Emil Kowalski's animations.dev course for learning similar animation techniques—validates that course as a reference for building iOS-quality web interactions.
