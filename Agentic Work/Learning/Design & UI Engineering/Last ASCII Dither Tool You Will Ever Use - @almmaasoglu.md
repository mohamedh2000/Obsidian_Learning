### Context: ASCII Art and Dithering

ASCII art converts images to text characters, mapping pixel brightness to character density. Dithering (like Floyd-Steinberg) distributes quantization error across pixels to create smoother gradients with limited palettes. Together, these techniques create distinctive retro/terminal aesthetics popular in creative coding and indie games.
