# Autoresearch Autonomous LLM Training - @karpathy

> I packaged up the "autoresearch" project into a new self-contained minimal repo. It's basically nanochat LLM training core stripped down to a single-GPU, one file version of ~630 lines of code. The human iterates on the prompt (.md), the AI agent iterates on the training code (.py). The goal is to engineer your agents to make the fastest research progress indefinitely and without any of your own involvement.
