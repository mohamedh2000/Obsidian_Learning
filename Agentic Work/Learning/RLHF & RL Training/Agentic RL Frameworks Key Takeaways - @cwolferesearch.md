# Agentic RL Frameworks Key Takeaways

> Agentic RL frameworks need modular environments, richer trajectory structures, action masks, process rewards, async rollouts, and curricula to train long-horizon agents effectively.

## Key Points

- Agentic RL frameworks increasingly use modular interfaces for tools and environments so tasks, backends, and training setups can be swapped without major code changes.
- Rollouts need step-level structures that preserve instructions, generated tokens, tool calls, observations, rewards, and environment state without retokenization drift.
- Long-horizon agents benefit from process rewards, broader advantage normalization, async rollout generation, containerized environments, and explicit curriculum design.
