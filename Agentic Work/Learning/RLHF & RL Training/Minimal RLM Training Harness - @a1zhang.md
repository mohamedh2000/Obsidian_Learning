## Key Points

- Minimal training harness built on prime-rl and verifiers for training RLMs without sandboxes
- Code available in `training/` folder of the RLM GitHub repo
- RLM-Qwen3-30B-A3B-v0.1 trained using RL on separate split of environments (OOLONG-Spam, BC+ split)
- Significantly improved performance on long-context tasks from the original RLM paper
- Trained for 1 day on 8xA100 using prime-rl
- Model and code are open-source (GitHub + Huggingface)
