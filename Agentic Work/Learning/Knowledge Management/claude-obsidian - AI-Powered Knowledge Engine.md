## Key Points

- Auto-organizes ingested content into entities, concepts, and sources
- Flags contradictions across vault with callouts linking to sources
- Runs autonomous 3-round web research and files output automatically
- Parallel batch ingestion for multiple sources at once
- Queries cite specific wiki pages, not fuzzy similarity matches
- Native Obsidian Bases dashboard plus visual canvas companion
- Cross-project setup lets one vault feed all Claude Code projects
- 100% open source: https://github.com/AgriciDaniel/claude-obsidian
