## Key Points

- Step 1: create an Obsidian vault and install the Web Clipper extension.
- Step 2: point Claude Code at the vault, feed it Karpathy's gist, and let it build the folder structure and CLAUDE.md schema.
- Step 3: clip articles straight into raw/ and tell Claude Code to ingest them.
- Step 4: ask questions and get answers straight from the wiki with citations already built in.
- Step 5: run a periodic "lint" pass so the agent catches contradictions and dead links on its own.
