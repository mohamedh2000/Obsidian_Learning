# The Complete Guide to Building Skills for Claude (PDF)

> Anthropic frames skills as portable instruction folders that capture repeatable Claude workflows once and reuse them everywhere.

Official Anthropic guide on creating Claude Code skills (slash commands). Covers skill structure, frontmatter configuration, prompt engineering for skills, and best practices for building reusable automation within Claude Code.

## Key Points
- Defines a skill as a folder centered on `SKILL.md`, with optional `scripts/`, `references/`, and `assets/`.
- Explains progressive disclosure: frontmatter advertises the skill, `SKILL.md` carries the core instructions, and linked files are loaded only when needed.
- Treats skills as portable across Claude.ai, Claude Code, and the API, and emphasizes planning use cases, then testing, iterating, and distributing deliberately.
