## Key Points
- The prompt instructs the agent to conduct multi-round, recursive research starting with shallow passes and deepening iteratively
- Each iteration generates new questions based on prior findings — creating a knowledge spiral rather than linear search
- Cross-checking and reflection are built into the loop: the agent validates information and initiates deeper research when needed
- Final output is a 10,000+ word professional website with modern styling — treating documentation as a design artifact

### The Prompt Structure
1. **Start shallow** — gather up-to-date surface-level information
2. **Generate deeper questions** — based on initial findings, formulate more insightful queries
3. **Iterate with full-text review** — multiple search rounds with deep literature dives
4. **Dynamically expand scope** — update research plan as new threads emerge
5. **Cross-check and reflect** — validate findings, initiate deeper dives where uncertainty remains
6. **Output as website** — compile into 10K+ words, implemented with modern web standards

### Why It Matters
This is a meta-prompt for autoresearch: instead of one-shot querying, it programs the agent to recursively deepen its understanding. The website output format forces synthesis rather than raw dump — treating research output as a first-class product.
