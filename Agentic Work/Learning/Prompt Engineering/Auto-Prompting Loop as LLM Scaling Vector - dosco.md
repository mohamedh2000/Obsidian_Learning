# Auto-Prompting Loop as LLM Scaling Vector

Auto-prompting loop is an under-explored LLM scaling vector. Instead of scaling model size or compute, you scale the quality and structure of the prompts themselves through iterative optimization.

## Key Points

- Prompt optimization as an alternative scaling dimension
- Auto-prompting creates iterative refinement loops
- Complements traditional scaling (params, compute, data)
- Links to DSPy, GEPA, and autoresearch paradigms
