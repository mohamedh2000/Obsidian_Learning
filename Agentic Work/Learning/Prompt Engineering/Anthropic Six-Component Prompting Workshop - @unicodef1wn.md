## Tweet

Anthropic's team said it straight: most people prompt Claude wrong. They released a free 24-minute workshop on how they build a real prompt. A real prompt runs on six components — most people use one and call it done. The other five: structure, context, examples, constraints, feedback. I built a Claude Skill that adds all six on its own — write your request the normal way and the skill restructures it before Claude reads it.
