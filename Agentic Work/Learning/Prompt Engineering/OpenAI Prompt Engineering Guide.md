## Key Points

- Message roles and instruction following — developer, user, assistant role separation
- Prompt structure pattern: Identity → Instructions → Examples → Context
- Use XML tags to delineate content boundaries, Markdown headers for logical sections
- Pin production apps to specific model snapshots and build evaluations to monitor prompt performance
- Reusable prompts with variables via OpenAI dashboard
