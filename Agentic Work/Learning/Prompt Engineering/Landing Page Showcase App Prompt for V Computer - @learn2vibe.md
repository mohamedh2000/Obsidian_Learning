## Key Points
- **Prompt structure**: Defines a landing page showcase app where users browse and preview different design options
- **Iterative learning**: System learns from user feedback to improve future landing page generations
- **Web research integration**: When asked without direction, searches for trending landing page styles
- **Brand alignment**: Asks follow-up questions about styling if user doesn't specify brand guidelines

### Prompt Template Structure
1. **Core app definition**: Internal design directory for browsing landing page variations side-by-side
2. **Initial seed**: Starts with 3 landing pages in the directory
3. **Feedback loop**: User provides thoughts → changes propagate to all future generations
4. **Autonomous research**: Searches web for trending styles when no specific direction given
5. **Brand guardrails**: Ensures generated pages align with company style + user preferences

### The V Computer Context
V Computer (@v_computer) is an AI coding tool built on Claude Code. This prompt demonstrates how to structure complex generative UI tasks with learning loops and external research integration.
