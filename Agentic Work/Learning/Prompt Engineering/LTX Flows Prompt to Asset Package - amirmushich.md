## Key Points

- Start with a prompt to generate a brand board
- Use the pipeline scheme from the video reference
- Structure prompts with: headline, subheader, CTA, key visual description
- Include aesthetic direction (sunny, happy, bright imagery, lifestyle)
- Reference image serves as brand base

## Sample Prompt Structure

```
make a social media publication design using the reference image as a brand base
headline = [Event/Title]
subheader = [Supporting text]
CTA = [Call to action with date/time]
Key visual = [Subject description with aesthetic direction]
```
