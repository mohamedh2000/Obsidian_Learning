## Key Points

- **Cast Rules Section**: Explicitly defines character appearance to prevent duplication and maintain visual consistency across frames
- **Location Anchoring**: Establishes persistent environmental details (wet NYC block, bodega gate, neon signs, steam) for scene coherence
- **Timeline Breakdown**: Precise 2-second intervals with specific actions and camera movements
- **Camera Direction Language**: Uses cinematography terms (low tracking shot, handheld chase, top-down shot, wide shot) to guide generation
- **Visual Effects Cues**: Glowing elements (keys, lock seals, amber chains) as consistent magical system

```
┌────────────────────────────────────────────┐

│  - Reference assets: @VictorBodega, @Thugs │
│  - Explicit exclusion: "Do not duplicate"  │
│  - Visual markers: tank top, shorts, keys  │
└────────────────────────────────────────────┘
              │
              ▼

              │
              ▼
┌────────────────────────────────────────────┐
│  CAMERA (shot list)                        │
│  - Low tracking behind                     │

```

## Template Elements to Reuse

1. **Character Locking**: "Only one [character] appears... Do not duplicate [character]"
2. **Visual Marker Definition**: Specific clothing + distinctive prop (glowing keys)
3. **2-Second Beat Structure**: Each interval has ONE action + ONE camera instruction
4. **Transition Cues**: "without turning around", "before the thug can touch him"
5. **Atmosphere Persistence**: Repeated references to wet pavement, steam, neon throughout
