## Key Points

- The "mismanaged geniuses hypothesis" posits that human prompting is suboptimal for accessing model capabilities
- GEPA + Claude validator loops reveal that smaller models (Gemini Flash/Lite) can solve problems beyond expected capabilities
- Proposes next breakthrough: letting models loop and fix the original prompt vs chain-of-thought forward-fixing

## Full Text

>
> run enough GEPA + Claude validator loops and you see gemini flash / lite solve stuff you didn't think it could.
>
> maybe the next jump is figuring out how to let these models loop and fix the original prompt vs fixing forward like chain of thought.
