# AI Prompt Library - For Designers

> A design-focused prompt library for stealing, remixing, and operationalizing prompts instead of starting from a blank box each time.

A collection of AI prompts curated specifically for design professionals. Create, remix, and ship prompts for design workflows and projects.

## Key Points
- Curates reusable prompts, style references, and techniques aimed at design workflows rather than generic prompting.
- Positions the library as a remixable resource shaped by lessons taught to more than 300 designers across teams like Google, Figma, Uber, and Reddit.
- Works best as a reference set for turning repeated design tasks into more consistent AI-assisted workflows.
