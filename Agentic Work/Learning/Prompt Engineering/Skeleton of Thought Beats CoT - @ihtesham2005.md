## Key Points

- Skeleton of Thought (SoT) prompting outlines all points first, then expands each independently in parallel -- unlike CoT which forces sequential token generation
- Stanford paper shows 2.39x average speedup; on GPT-4 quality held or improved on structured tasks
- SoT dominates for how-to guides, listicles, technical comparisons; CoT still wins where sequential dependency is real (math proofs, debugging chains)
