# Graph Database Deep Dive

> Graph databases earn their keep when relationship paths are the core query shape, not just another way to store rows.

Local HTML diagram exploring graph database concepts, traversals, and use cases.

**Local file:** `~/.agent/diagrams/graph-database-deep-dive.html`

## Key Points
- Graph models treat nodes and edges as first-class entities, which makes multi-hop relationship traversal natural instead of join-heavy.
- They become compelling when the path matters: recommendation trails, provenance chains, knowledge graphs, or repeated relationship walks.
- Graph algorithms and traversal power come with modeling and operational overhead, so SQL is still the better default for shallow CRUD data.
