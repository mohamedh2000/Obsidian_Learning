# Database Paradigms and Vectors

> Pick the database that matches the question shape, and add vectors or graph layers alongside PostgreSQL instead of ripping it out.

Local HTML diagram covering different database paradigms with a focus on vector databases.

**Local file:** `~/.agent/diagrams/database-paradigms-and-vectors.html`

## Key Points
- Different database families answer different question shapes: relational for exact facts, vector for similarity, graph for traversal, and time-series for measurements over time.
- Recommends adding `pgvector` alongside PostgreSQL instead of replacing the main relational store.
- Frames vector and graph layers as additive when semantic retrieval or multi-hop intelligence features outgrow indexed SQL queries.
