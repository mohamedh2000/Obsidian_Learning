# Virtual Filesystem for AI Agents

> "Virtual filesystem" means two different things depending on who you ask. In operating systems: a layer for uniform file operations. In AI agents: a filesystem-shaped interface over persistent storage, so agents can run ls, cat, find, and grep over a database.
