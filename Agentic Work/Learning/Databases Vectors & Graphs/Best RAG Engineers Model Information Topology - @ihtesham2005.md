## Key Points

- Naive RAG pipelines fail because chunk-embed-retrieve ignores document structure, dependencies, and logical units.
- Better retrieval systems index smaller semantic units, preserve hierarchies, and pull structurally related context instead of only nearest vectors.
- Query decomposition matters because many production RAG problems are information-modeling failures before they become retrieval failures.
