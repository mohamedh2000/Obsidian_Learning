## Key Points

- **Step 1**: Image replication system (Nano Banana Pro) generates prompt from Pinterest reference
- **Step 2**: GPT Image 2 creates the base image from prompt
- **Step 3**: Storyboard skill on Claude Fable 5 generates 6-panel storyboard
- **Step 4**: Seedance 2.0 generates video from storyboard + reference image

### Prompt Structure (GPT Image 2)

```
CHARACTER = [description]
CREATURE = [description]
PALETTE = [colors]
BACKGROUND = [flat description]

DO: [detailed staging instructions]
STYLE: [style tags]
CAMERA: [shot type]
MOOD: [emotional tags]
RULES: [constraints]
NO: [exclusions]
```

### Storyboard Prompt Structure

- PROJECT CARD with meta info
- CONTINUITY HEADER
- SCENE PACKET (premise, location, action chain, prop states)
- CHARACTER SANITIZATION (remove non-visual traits)
- DIRECTOR STRIP (beat line, camera path, rhythm track, escalation map)
- 6-panel grid for single continuous sequence

### Seedance Prompt Structure

- Reference storyboard as "director-approved blueprint"
- Character reference for identity consistency
- Environment locks, emotional guidance, visual style
- Panel-by-panel beats with audio notes
