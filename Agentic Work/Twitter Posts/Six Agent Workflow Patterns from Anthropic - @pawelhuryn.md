> Six patterns for building dynamic workflows and loops identified by Anthropic: Classify-and-act, Fan-out-and-synthesize, Adversarial verification, Generate-and-filter, Tournament, Loop-until-done.

## Key Points

- **Classify-and-act**: one agent decides type, script routes (bug vs feature vs noise)
- **Fan-out-and-synthesize**: one agent per piece, merged in code (market research, competitor teardown)
- **Adversarial verification**: separate agent checks output against rubric (fact-checking PRD)
- **Generate-and-filter**: many candidates, deduped, survivors kept (naming, positioning, ideation)
- **Tournament**: agents attempt task different ways, judges compare until one wins (product strategy)
- **Loop-until-done**: spawn until stop condition (implement, document, test in one shot)
