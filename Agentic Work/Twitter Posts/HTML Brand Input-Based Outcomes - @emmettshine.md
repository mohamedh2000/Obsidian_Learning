## Key Points

- Deliverable has shifted: zip folder with `/human`, `/agent` folders + readme.md replaces traditional outputs
- Brand encoded as instructions: YAML, JSON, Markdown, HTML, CSS, SVG files
- Founder dropped packet into Cursor → near-complete landing page same day
- Value is moving upstream to the 0-to-1 work: research, synthesis, positioning judgment calls
- Claude Design accessibility + organized files has been breakthrough at @littleplainsxo
- Agency model is fundamentally shifting - paying for inputs not outputs
- "magic-trick.md" concept mentioned as the human creative edge
