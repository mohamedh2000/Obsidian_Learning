## Key Points

- Highlights `tmchow/illo-skill`, an agent skill for generating original print-style editorial illustrations.
- Gives agents a consistent mascot or character face across generated images.
- Includes ten bundled visual looks plus support for custom characters and styles.
- Supports Codex CLI image generation and OpenRouter-backed model selection.
- Installable from GitHub at `https://github.com/tmchow/illo-skill`.
