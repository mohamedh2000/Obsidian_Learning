## Key Points

- Creates complete, presentation-ready brand guideline boards
- Intelligence rule: analyze logo first, infer 3 identity traits
- Color system: extract palette from logo automatically (primary, secondary, accent with HEX codes)
- Typography system: match personality (luxury → serif, tech → geometric sans, street → bold condensed)
- Includes gradients, color combinations, tonal variations
- Goal: agency-grade, client-deliverable output

## Full Prompt

```
PROMPT: Using the uploaded logo for (Brand name) generate a high-end, agency-grade brand identity system poster.

OBJECTIVE: Create a complete, presentation-ready brand guideline board that looks like it was designed by a top branding studio. The result must feel commercial, realistic, and client-deliverable, not conceptual.

INTELLIGENCE RULE: Before designing, analyze the logo and infer 3 identity traits.

COLOR SYSTEM (SMART GENERATION):
- Extract palette from logo automatically
- Include: Primary colors (3–5), Secondary colors (3–5), Accent colors
- Each must show: HEX codes, labeled usage (primary / UI / highlight / background)
- Generate: gradients, color combinations, tonal variations

TYPOGRAPHY SYSTEM (MATCH PERSONALITY):
- luxury → elegant serif
- tech → geometric sans
- street → bold condensed
```
