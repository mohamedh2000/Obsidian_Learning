## Key Points

- **Meetily** — local-only meeting-note AI (Parakeet/Whisper transcription), keeps confidential meetings off the cloud. https://github.com/Zackriya-Solutions/meetily
- **agent-skills** — production-level skills for AI coding agents (test/review/refactor). https://github.com/addyosmani/agent-skills
- **system_prompts_leaks** — database of leaked system prompts from Claude, ChatGPT, Gemini, Grok. https://github.com/asgeirtj/system_prompts_leaks
- **OfficeCLI** — CLI letting agents read/write Word/Excel/PowerPoint, single binary, no Office install. https://github.com/iOfficeAI/OfficeCLI
- **Orca** — manage multiple coding agents in parallel on your own subscription, desktop or mobile. https://github.com/stablyai/orca
- **OmniRoute** — free gateway to 231+ AI providers via one endpoint, with token compression. https://github.com/diegosouzapw/OmniRoute
- **claude-video** — lets Claude "watch" video: download, frame extraction, transcription. https://github.com/bradautomates/claude-video
- **page-agent** — browser agent driven by natural language, embeddable in a page. https://github.com/alibaba/page-agent
- **Astryx** — Meta's open-source design system built for humans and AI agents to build UI the same way. https://github.com/facebook/astryx
- **CubeSandbox** — lightweight sandbox for AI agents, instant startup, strong isolation. https://github.com/TencentCloud/CubeSandbox
