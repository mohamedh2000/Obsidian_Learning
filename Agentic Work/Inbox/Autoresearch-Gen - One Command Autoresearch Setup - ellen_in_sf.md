# Autoresearch-Gen — One Command Autoresearch Setup

Started doing AI research 9 months ago, despite 6 years as data scientist/ML engineer. Seeing @karpathy's autoresearch made it accessible. Built autoresearch-gen that lets you run autoresearch with one command + generate dashboard — it works locally on a MacBook too.

It scaffolds the autoresearch setup, runs experiments, and gives you a dashboard to track results.
