# Slate

Slate is an RLM (Reinforcement Learning Model) coding agent with an OS-like architecture for managing context and multi-agent coordination.

## Notes

- [[Slate Agent Architecture and Context Management - cedric_chee]] — Architecture analysis: context as scarce RAM, thread/episode design, systems > model capability

## Key Themes

- **Context management**: The core innovation — treating context like scarce memory, routing it carefully
- **Agent OS**: Not another prompt stack, but an operating system for agents
- **Sub-agent visibility**: Full observability into what agents are doing (Numman's highlight)
