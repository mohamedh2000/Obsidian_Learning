# Quick Capture Inbox

This folder is for **fast link dumps**. Don't worry about categorizing — just get the link in here.

## How to capture

### From desktop (fastest)
1. Press `Cmd+P` → type "new note" → paste your link
2. Or use the **QuickAdd** plugin (set up a hotkey like `Cmd+Shift+N`)

### From phone
1. Open Obsidian → tap the `+` button → paste link → save to Inbox/

### From browser
1. Install **Obsidian Web Clipper** extension
2. Set default save location to `Inbox/`
3. Click the extension icon on any page → Save

## Sorting later
When you have time, move notes from `Inbox/` to the appropriate `Reading List/` topic folder and fill in the `topic:` field in the frontmatter.

The Reading Dashboard tracks both `Inbox/` and `Reading List/` notes.
