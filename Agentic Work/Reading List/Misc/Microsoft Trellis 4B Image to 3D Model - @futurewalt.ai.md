## Key Points

- 4B parameter model turns images into 3D assets in 3 seconds
- Uses new O-Voxel geometry format - converts to textured mesh in under 100ms on CUDA
- Generates GLB files with full PBR textures - ready for Blender, Unity, Unreal Engine
- 100% open source
- Major implications for 3D creators, game devs, and virtual world builders
