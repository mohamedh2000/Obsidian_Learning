## Key Points

- Uses Nano Banana 2 (Google's advanced image model) inside invideo
- Prompt structure built around three variables: body part, skin tone, and imperfections
- Fixed parameters: 45-degree raking sidelight, lifted blacks, zero digital sharpening, optical depth of field
- Animation with Kling 2.6 for final output
- Includes prompts for ears, forehead, lips, eyes, neck tattoos, fingers
