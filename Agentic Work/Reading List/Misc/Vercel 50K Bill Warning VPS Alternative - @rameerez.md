## Key Points

### The Economics

Serverless platforms like Vercel charge per-request, which can scale unpredictably when traffic spikes. A fixed-cost VPS provides a cost ceiling regardless of traffic. For projects that go viral, the difference can be 10x-100x in hosting costs.
