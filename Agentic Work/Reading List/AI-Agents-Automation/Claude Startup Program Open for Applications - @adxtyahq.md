## Key Points

- **Up to ~$25K in API credits**: Significant runway for early-stage startups building on Claude—enough to prototype, iterate, and find product-market fit
- **No VC requirement**: Unlike OpenAI's startup program which often requires institutional backing, Anthropic accepts bootstrapped founders
- **Selection criteria**: Product quality and demonstrated Claude usage matter more than fundraising status—favors builders over pitch decks
- **Apply directly**: https://www.anthropic.com/startups
