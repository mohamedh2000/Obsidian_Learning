# PinchTab Browser Control for Agents - @simplifyinai

> BREAKING: The biggest bottleneck for AI agents just got solved by a 12MB file. PinchTab is a tiny 12mb go binary that gives any AI agent full browser control through a plain HTTP API. You just send a request and it clicks, types, and navigates. It manages Chrome instances, bypasses bot detection, and reduces token usage by 13x by parsing the accessibility tree instead of taking expensive screenshots.
