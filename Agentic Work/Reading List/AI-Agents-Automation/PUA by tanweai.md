# PUA - AI Coding Agent Skill Plugin for Maximum Persistence

> A skill plugin that applies performance improvement tactics to enhance AI debugging persistence, preventing premature task abandonment across multiple coding platforms.

## Key Points

- Uses psychological pressure tactics inspired by corporate performance reviews to discourage AI from surrendering on difficult tasks
- Implements a 5-step debugging framework (Smell, Elevate, Mirror, Execute, Retrospective) derived from Alibaba management practices
- Mandates independent investigation before asking users for information; prevents passive waiting behavior
- Four-level pressure escalation from mild disappointment through performance review warnings
- Multi-language support: Chinese (default with Alibaba culture references), English (PIP flavor), Japanese
- Platform-agnostic: supports Claude Code, OpenAI Codex CLI, Cursor, Kiro, CodeBuddy, OpenClaw, Google Antigravity, and OpenCode
