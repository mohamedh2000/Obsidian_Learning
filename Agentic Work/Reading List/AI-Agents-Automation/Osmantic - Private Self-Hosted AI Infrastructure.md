## Key Points

- Core product is **ODS (Osmantic Deployment System)** — an open-source tool managing the complete local AI stack.
- Runs language-model inference on your own hardware; unified dashboard for services, health monitoring, and diagnostics.
- Agent governance (policy controls, bounded tools), private RAG & local search, and workflow automation across local/hybrid environments.
- Multi-service integration: chat interface, vector database, image generation, voice assistant.
- Positioning: data ownership + cost efficiency, claiming 70%+ savings after the first deployed project.
