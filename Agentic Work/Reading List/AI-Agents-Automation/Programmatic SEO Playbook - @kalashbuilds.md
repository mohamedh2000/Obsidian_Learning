## Key Points
- **Templates pattern** (`[type] template`) targets high-intent searches like resume/invoice templates — requires paid-level quality and frictionless usage
- **Curation pattern** (`best [category]`, `top [number] [things]`) captures decision-stage commercial traffic with evergreen lists requiring clear criteria and real testing
- **Conversions pattern** (`[x] to [y]`) provides instant utility tools like unit/format converters — needs accurate data and mobile-first design
- **Comparisons pattern** (`[x] vs [y]`, `[x] alternative`) targets high purchase intent with side-by-side analysis — requires honest feature data
- **Examples pattern** (`[type] examples`) serves research-phase traffic with curated real-world inspiration collections
- **Locations pattern** (`[service] in [location]`) captures massive local intent with geographic scalability — needs real local data and maps
- **Personas pattern** (`[product] for [audience]`) creates persona-specific landing pages for targeted use-case messaging

### URL Structure Best Practices
Each pattern has recommended URL structures:
- Templates: `/templates/[type]/` or `/templates/[category]/[type]/`
- Curation: `/best/[category]/` or `/[category]/best/`
- Conversions: `/convert/[from]-to-[to]/` or `/[from]-to-[to]-converter/`
- Comparisons: `/compare/[x]-vs-[y]/` or `/[x]-vs-[y]/`
- Locations: `/[service]/[city]/` or `/locations/[city]/[service]/`

### Value Requirements
The playbook emphasizes that each pattern requires specific value thresholds — programmatic SEO fails when pages lack genuine utility. Templates must be usable, curation must show real testing, comparisons must be honest, and local pages must have actual listings.
