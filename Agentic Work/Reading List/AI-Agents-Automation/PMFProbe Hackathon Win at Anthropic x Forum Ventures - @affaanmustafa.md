## Key Points
- **PMFProbe** won the Anthropic x Forum Ventures hackathon in NYC, earning $15K in Anthropic API credits
- The tool is designed for **pre-MVP idea validation**—helping founders test product-market fit before writing code
- Built by @affaanmustafa (cogsec) and @DRodriguezFX as a collaborative project
- Targets the "0 → 1" founder journey, the riskiest phase where most startups fail due to building something nobody wants

### Why It Matters
Most validation tools assume you already have a product. PMFProbe operates earlier in the lifecycle—when you only have an idea. This is the highest-leverage intervention point for startup success.
