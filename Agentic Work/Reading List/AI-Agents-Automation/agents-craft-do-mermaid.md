# Beautiful Mermaid - Mermaid Rendering, Made Beautiful

> Craft's Beautiful Mermaid is a diagram-rendering tool aimed at AI workflows, with fast themed output and support for both SVG and ASCII exports.

Open-source Mermaid rendering library built for the AI era. It focuses on fast, themeable diagram output and supports multiple diagram families beyond plain flowcharts.

## Key Points

- The tool supports flowchart, state, sequence, class, and ER diagrams, which makes it broad enough for both engineering docs and agent-generated visualizations.
- The site emphasizes presentation quality with multiple built-in themes instead of only raw Mermaid-to-SVG conversion.
- SVG and ASCII output modes make it useful in both browser-based docs and terminal or agent contexts where plain-text rendering still matters.
