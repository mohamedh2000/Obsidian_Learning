# The Agency - AI Specialist Agent Collection

> The Agency packages a large roster of personality-driven specialist agents that can be installed into Claude Code directly or adapted for other AI coding tools.

A curated collection of specialized AI agent personalities for Claude Code and other AI tools. Pre-built agent personas span engineering, design, sales, marketing, product, and other domains, each with distinct expertise, communication style, and deliverables.

## Key Points

- Each agent is designed as more than a prompt stub: the repo emphasizes role-specific workflows, deliverables, and personality patterns that make the specialists easier to activate repeatedly.
- The project supports multiple adoption paths, including copying agents into `~/.claude/agents/` or generating integration files for tools like Cursor, Aider, Windsurf, and Gemini CLI.
- The repo has strong public traction, with more than 58k GitHub stars at enrichment time, which makes it a useful reference point for the current agent-personality ecosystem.
