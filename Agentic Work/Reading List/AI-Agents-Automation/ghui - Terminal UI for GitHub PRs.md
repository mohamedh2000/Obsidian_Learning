## Key Points

- ghui is a terminal-based UI for managing GitHub pull requests across multiple repositories
- Features vim-like keyboard navigation for efficient PR management
- Capabilities include: PR filtering, draft toggling, label management, opening PRs in browser
- Requires Bun runtime and authenticated GitHub CLI
- All operations happen without leaving the terminal
