## Key Points

- **Three execution modes**: Agents (persistent workers), Workflows (visual automation), Goals (autonomous objectives)
- **60+ workflow nodes** with triggers, branching logic, and event automation
- **15+ AI provider integrations** out of the box
- **Local-first architecture**: Express.js backend + SQLite + filesystem
- **Docker support**: Full (1.5GB with browser automation) or Lite (715MB)
- **Desktop app**: Electron for Windows, macOS, Linux
- **Vue 3 + Vite frontend**
