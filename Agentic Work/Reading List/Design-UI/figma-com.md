# Figma

> Figma remains the broad collaborative interface design platform for brainstorming, designing, prototyping, handoff, and increasingly AI-assisted product creation.

## Key Points

- The platform spans design, Dev Mode, FigJam, Slides, Draw, Sites, and Make, so the workflow goes beyond static interface mockups.
- Its current positioning also includes AI features and an MCP catalog that connects Figma workflows to AI coding tools.
- The ecosystem is backed by a large community layer of plugins, templates, UI kits, widgets, resources, and enterprise collaboration features.
