# Paper

> Paper pitches itself as a connected canvas where teams shipping with agents can keep design, code, data, and collaboration in one place.

## Key Points

- The product is presented as a modern design tool built on web standards rather than a traditional isolated design file format.
- Its core message is reducing translation loss between designers, agents, code, and product context by keeping them on one shared canvas.
- Paper is available as both a desktop app and a browser-based experience, aimed at teams doing collaborative product and interface work.
