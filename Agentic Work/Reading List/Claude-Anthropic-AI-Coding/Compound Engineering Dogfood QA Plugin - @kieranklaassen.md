## Key Points

- New `/ce-dogfood-beta` command in compound-engineering plugin
- Autonomous QA that diffs against main branch
- Builds full browser test matrix of every change as user journeys
- Drives the app like a real user would
- Auto-fixes broken tests, adds regression tests, commits each fix
- Runs until test matrix is green — then you ship
