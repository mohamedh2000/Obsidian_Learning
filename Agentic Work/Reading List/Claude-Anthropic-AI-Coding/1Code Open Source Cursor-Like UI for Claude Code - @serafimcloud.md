## Key Points
- **Cursor-Like Interface**: 1Code brings the Cursor IDE's UX paradigm to Claude Code — familiar side-panel AI chat + code editing experience for those who prefer visual interfaces over terminal
- **Open Source**: Unlike Cursor (proprietary), 1Code is open source — inspectable, modifiable, and forkable for custom workflows
- **Claude Code Backend**: Uses Claude Code as the underlying agent, meaning you get Anthropic's agent capabilities with a graphical wrapper
- **Fills the GUI Gap**: Claude Code's terminal-first approach is powerful but alienates developers who prefer VS Code-style visual workflows — 1Code bridges that gap

### Why This Matters
The 765 likes indicate significant interest in GUI alternatives to Claude Code's CLI. This positions 1Code as the open-source answer to the "I want Cursor but with Claude Code's agent" request that's been common in developer communities.
