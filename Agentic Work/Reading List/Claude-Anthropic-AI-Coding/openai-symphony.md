# OpenAI Symphony Autonomous Implementation Runs

> Symphony moves one level above supervising coding agents: it treats project work as isolated runs that produce proof, surface review artifacts, and land changes safely.

## Key Points

- The repo is an engineering preview for trusted environments, not a finished turnkey product.
- OpenAI positions Symphony as a way to manage work queues instead of micromanaging agent conversations.
- Current paths are either to implement the public spec yourself or to try the experimental Elixir reference implementation.
