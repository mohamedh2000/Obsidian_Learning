# From Claude Code to Figma

> Figma's Claude Code workflow captures a live UI from the browser and turns it into editable Figma frames so teams can review, compare, and iterate on real built interfaces.

## Key Points
- The workflow can capture production, staging, or localhost UIs from Claude Code directly into editable frames on the Figma canvas.
- Figma positions the canvas as the place to compare multi-step flows, explore alternatives, and let designers, engineers, and PMs react to the same artifact earlier.
- Refined frames can roundtrip back into code through the Figma MCP server so the design context is not lost when moving back to implementation.
