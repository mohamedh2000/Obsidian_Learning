# Claude Code to Figma Code to Canvas Workflow

> Muzli explains Code to Canvas as a round-trip workflow: build in Claude Code, capture the live UI into Figma, review on the canvas, then send refined designs back into code.

## Key Points

- The workflow uses Figma's local Dev Mode MCP server to convert a running browser UI into editable Figma frames.
- It is positioned for teams already prototyping in code who still need collaborative design review, side-by-side comparison, and annotation on canvas.
- The article calls out current limits too: desktop-app-only setup, token costs for large multi-screen flows, and no visual code-side refinement loop yet.
