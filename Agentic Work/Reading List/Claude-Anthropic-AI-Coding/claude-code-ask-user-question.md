# Claude Code AskUserQuestion Tool Guide

> The AskUserQuestion tool turns ambiguous coding requests into an interview-first workflow, letting Claude gather constraints before it starts building.

## Key Points

- The recommended pattern is interview, then spec, then a fresh execution session once the ambiguity has been removed.
- It replaces silent assumptions with explicit user choices about architecture, implementation, and tradeoffs.
- Cyrus extends the same behavior into Linear so issues can pause for input asynchronously and preserve the decision trail in the ticket history.
