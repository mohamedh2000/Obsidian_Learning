# ClaudeKit Spec Driven Workflow - @dani_avila7

> Found an interesting Claude Code workflow from ClaudeKit. The flow goes like this: /docs:init scans your codebase and generates specs, /brainstorm challenges you with questions until requirements are solid, /plan creates a phased implementation plan, /clear resets context for clean output, /code:auto implements phase by phase using progressive disclosure.
