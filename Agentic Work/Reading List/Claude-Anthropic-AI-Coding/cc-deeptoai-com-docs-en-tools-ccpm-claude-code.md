# CCPM Claude Code Project Manager

> CCPM packages spec-driven Claude Code workflows around PRDs, epics, GitHub issues, and parallel agents so project state stays auditable from planning through execution.

## Key Points

- CCPM structures work into five phases: brainstorm, document, plan, execute, and track.
- The system turns PRDs into epics and then into concrete task files that can be synchronized to GitHub issues.
- Its main promise is traceability: keep project context and progress in files and issue history instead of losing it inside long chat sessions.
