# Generative UI JSON Render Modes - @ctatedev

> Generative UI in json-render has two modes: inline - AI outputs text + JSONL patches interleaved. It decides when UI beats text. For chatbots, copilots, assistants. standalone - JSONL patches only. No prose. Prompt in, UI out. For website builders, text-to-widget, dashboards.

## Key Points

- json-render supports two generative UI modes: inline (text + JSONL patches) and standalone (JSONL only)
- Inline mode for chatbots and copilots; standalone for website builders and dashboards
- AI decides when UI components are better than text in inline mode
