# Claude Code Remote Control Docs

> Anthropic's Remote Control docs describe a way to keep Claude Code running locally while browser and phone clients act as synced windows into that local session.

## Key Points

- Remote Control can be started in server mode with `claude remote-control`, on an interactive session with `claude --remote-control`, or from inside a running session with `/remote-control`.
- The session stays on your machine, so your filesystem, MCP servers, tools, and project config remain local.
- Requirements include Claude Code v2.1.51 or later, Claude.ai login, workspace trust, and admin enablement on Team or Enterprise plans.
