# Claude Code Productivity Advice - @arvidkahl

> Arvid Kahl recommends planning mode, deeper research, shared docs, and persisted markdown artifacts to make Claude Code work feel more reliable than ad hoc prompting.

## Key Points

- His first advice is procedural: use planning mode for non-trivial work, ask for deep research, and read or adjust the plan before execution.
- He also advocates maintaining a durable docs layer such as platform docs, ICP notes, style guides, roadmaps, and data references so context survives compaction.
- The post frames better AI coding outcomes as a documentation and workflow-design problem, not just a prompt-writing problem.
