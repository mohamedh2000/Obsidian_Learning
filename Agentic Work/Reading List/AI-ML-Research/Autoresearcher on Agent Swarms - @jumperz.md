## Key Points

- Mine message history and activity patterns to find a quiet window, then run 10-15 isolated experiments during dead hours.
- Evaluate prompt, config, routing, timeout, and coordination changes against real behavior logs instead of guessing in abstract.
- Keep the autoresearcher separate from the coordinator so the coordinating agent does not experiment on itself.
