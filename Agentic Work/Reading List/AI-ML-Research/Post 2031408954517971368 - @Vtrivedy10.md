## Key Points

- The harness includes prompts, tools, MCPs, sandboxes, orchestration logic, hooks, and verification surfaces around the model.
- Core primitives include durable storage, code execution, safe environments, memory/context injection, and access to current knowledge through web and external tools.
- Compaction and context management are treated as first-class harness concerns because agent quality decays as context grows.
