# Building Effective AI Coding Agents for the Terminal

> The OPENDEV paper argues that terminal-native coding agents become reliable when safety scaffolding, split planning and execution roles, and aggressive context management are built into the harness.

Paper on OPENDEV, a terminal-native coding agent architecture that emphasizes safety controls, workload-specialized model routing, dual planning and execution agents, and adaptive context compaction.

## Key Points

- The paper frames CLI-based agents as a better fit for long-horizon development work because they operate where developers already build, test, version, and deploy code.
- OPENDEV separates planning from execution, uses specialized model routing, and relies on lazy tool discovery to reduce context bloat and reasoning drift.
- It also emphasizes memory accumulation across sessions and event-driven reminders so repository knowledge compounds instead of resetting every run.
