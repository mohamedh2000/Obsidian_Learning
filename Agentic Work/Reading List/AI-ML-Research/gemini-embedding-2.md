# Gemini Embedding 2 - First Natively Multimodal Embedding Model

> Gemini Embedding 2 maps text, images, video, audio, and documents into one shared vector space so retrieval and similarity search can work across modalities instead of only within text.

Google's first fully multimodal embedding system that maps text, images, video, audio, and documents into a single vector space. It is aimed at cross-modal search, retrieval, and understanding workflows.

## Key Points

- The model is positioned as Google's first natively multimodal embedding offering instead of a text-first model with limited multimodal add-ons.
- A shared embedding space makes it possible to search images from text, compare documents against video or audio, and build broader retrieval systems.
- This is a useful reference point for multimodal RAG, semantic search, and ranking systems that need one representation layer across different media types.
