# OpenDev CLI Agent Design Paper - @omarsar0

> Pay attention to this one if you are building terminal-based coding agents. OpenDev is an 81-page paper covering scaffolding, harness design, context engineering, and hard-won lessons from building CLI coding agents. It introduces a compound AI system architecture with workload-specialized model routing, dual-agent architecture, lazy tool discovery, and adaptive context compaction.
