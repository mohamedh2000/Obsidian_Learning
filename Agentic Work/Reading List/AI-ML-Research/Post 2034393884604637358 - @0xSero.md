## Key Points

- Define multi-objective gates and strict metrics up front or the agent will optimize for a loophole instead of the intended outcome.
- Constrain what files can change, validate with tests, and keep atomic commits so long-running loops do not destroy the environment.
- Human check-ins are still necessary because unattended systems drift, create file sprawl, and optimize for "done" over correctness.
