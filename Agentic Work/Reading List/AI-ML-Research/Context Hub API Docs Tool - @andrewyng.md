# Context Hub API Docs Tool - @andrewyng

> I'm excited to announce Context Hub, an open tool that gives your coding agent the up-to-date API documentation it needs. Install it and prompt your agent to use it to fetch curated docs via a simple CLI. Coding agents often use outdated APIs and hallucinate parameters.
