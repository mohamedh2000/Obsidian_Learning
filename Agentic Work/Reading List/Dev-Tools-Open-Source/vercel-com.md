# Create a Vercel Integration

> Vercel's integration docs map the end-to-end path for shipping either a connectable account integration or a native marketplace product on the platform.

## Key Points

- The guide explains the approval flow, including the Create Integration form, review process, and the extra product-creation requirements for native integrations.
- It documents the operational fields an integration needs, such as redirect, webhook, and configuration URLs, API scopes, product metadata, billing details, and support links.
- The docs also stress install-flow quality: support both new and existing users, keep strong defaults, and minimize the number of steps during setup.
