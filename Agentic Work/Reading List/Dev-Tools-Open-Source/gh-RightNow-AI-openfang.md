# OpenFang - Open-Source Agent Operating System

> OpenFang is a Rust-based Agent OS that bundles agent runtime, tooling integrations, and a fast-moving open-source platform surface.

## Key Points

- The repository presents OpenFang as an open-source Agent Operating System rather than a narrow single-agent CLI.
- It is implemented in Rust and advertises support across agent-framework and MCP-oriented workflows.
- The maintainers describe it as feature-complete but still pre-1.0, with a recommendation to pin specific commits for production stability.
