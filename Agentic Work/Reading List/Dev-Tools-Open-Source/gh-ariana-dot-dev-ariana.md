# Ariana - Open-Source Agentic Development IDE

> Ariana positions itself as an open-source alternative to Cursor, Devin, and Ona for agentic development work.

## Key Points

- The README frames Ariana as an agentic development environment powered by the user's own Claude Code subscription or tokens.
- The project claims Ariana was built largely with Ariana itself, which makes the repo a product and dogfooding showcase.
- It targets desktop, web, and mobile web usage, with a hosted cloud version linked from the repository.
