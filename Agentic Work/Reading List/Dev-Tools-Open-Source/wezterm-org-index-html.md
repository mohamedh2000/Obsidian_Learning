# WezTerm - GPU-Accelerated Terminal Emulator

> WezTerm is a Rust terminal emulator with GPU acceleration, multiplexing support, and a large configuration/reference surface for power users.

## Key Points

- The site positions WezTerm as a cross-platform terminal emulator with a strong customization story rather than a minimal default shell wrapper.
- Its documentation surface includes downloads, configuration guides, CLI reference material, and a changelog for active users.
- Prominent feature areas include scrollback, quick select, copy mode, hyperlinks, and Lua-driven configuration.
