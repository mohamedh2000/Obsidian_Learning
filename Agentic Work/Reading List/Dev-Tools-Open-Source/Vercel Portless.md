# Portless - Stable Named Local URLs for Development

> Replace port numbers with stable, named `.localhost` URLs for local development -- designed for humans and agents.

## Key Points

- Eliminates the need to remember port numbers by mapping local dev servers to readable `.localhost` URLs instead of `localhost:3000`
- Automatic HTTPS/HTTP2 support with self-signed certificate generation
- Wildcard subdomain routing for multi-service development
- Git worktree integration for automatic branch-based URL prefixing
- Custom TLD support (`.test`, `.localhost`), static route registration for Docker containers, and Safari DNS compatibility
- Built with TypeScript (81.2%), uses pnpm workspaces and Turborepo; requires Node.js 20+; supports macOS, Linux, and Windows
