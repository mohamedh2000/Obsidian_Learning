# Why Factory Banned useEffect - @alvinsng

> Alvin Sng argues that banning direct `useEffect` usage made Factory's frontend code easier to reason about and harder for humans or agents to break accidentally.

## Key Points

- Factory avoids calling `useEffect` directly, reserving a narrow `useMountEffect()` helper for rare mount-time synchronization.
- The post says most effects are better expressed as derived state, event handlers, or data-fetching abstractions.
- This rule came from production bugs and is presented as even more important when coding agents tend to add defensive effects "just in case."
