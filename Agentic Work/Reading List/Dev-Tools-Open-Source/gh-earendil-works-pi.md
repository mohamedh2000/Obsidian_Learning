# Pi - AI Agent Coding Toolkit

> Self-extensible AI coding agent accessible through CLI and web interfaces - 47.3K stars.

## Key Points

- **pi-coding-agent**: Interactive CLI tool for working with an AI coding agent
- **pi-agent-core**: Runtime foundation handling agent operations, tool execution, and state tracking
- **pi-ai**: Unified API layer supporting OpenAI, Anthropic, and Google LLM providers
- Includes terminal UI library with differential rendering and web components for chat interfaces
- MIT licensed, TypeScript-based (96.5%)
- 47.3K stars, 5.6K forks, 4,048 commits
- Encourages sharing open-source work sessions to improve agent performance
