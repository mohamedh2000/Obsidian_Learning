# Superset

> Superset is a code editor for the AI agents era, built to run and review many CLI coding agents in parallel on one machine.

## Key Points

- The app orchestrates multiple agents across isolated git worktrees so parallel tasks can run without stepping on each other.
- It includes built-in monitoring, diff review, workspace handoff, and editor integration to reduce context switching while supervising agent output.
- The project positions itself as agent-agnostic, with first-class support for tools like Claude Code, Codex, Cursor Agent, Gemini CLI, and other terminal-based agents.
