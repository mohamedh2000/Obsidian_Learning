# Pi Messenger - Multi-Agent Chat Extension for Pi

> Pi Messenger lets multiple terminal agents share presence, tasks, file reservations, and chat-room style messages using files instead of a central daemon.

## Key Points

- The extension is built for the Pi coding agent and focuses on coordination between multiple agents working in the same folder.
- Its architecture is intentionally lightweight: no daemon, no server, just shared files and conventions.
- The repo also ships crew-agent integration so domain-specific worker skills can be loaded on demand during task execution.
