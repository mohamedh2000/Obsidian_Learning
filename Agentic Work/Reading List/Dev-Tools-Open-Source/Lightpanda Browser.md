# Lightpanda - Headless Browser Built from Scratch for AI Agents

> A purpose-built headless browser written in Zig, optimized for JavaScript execution and web automation with 9x less memory and 11x faster execution than Chrome.

## Key Points

- Not a Chromium fork or WebKit patch -- a completely new browser written in Zig from scratch
- Ultra-low memory footprint (9x less than Chrome) and exceptionally fast execution (11x faster than Chrome)
- JavaScript execution via V8 engine with partial Web API support (in development)
- Compatible with Playwright, Puppeteer, and chromedp through the CDP protocol
- Features include DOM tree and HTML parsing (html5ever), Ajax support (XHR and Fetch APIs), network interception, robots.txt compliance, cookie management, custom HTTP headers, and proxy support
- Licensed under AGPL-3.0; built with Zig 0.15.2 using V8, Libcurl, and html5ever
