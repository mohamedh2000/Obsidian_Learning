# Unpinched - PinchTab Security Scanner

> Unpinched is a point-in-time scanner for PinchTab and related browser-bridge artifacts that can hide beneath traditional endpoint tooling.

## Key Points

- Helixar positions the tool as a single-binary CLI that looks for PinchTab via ports, processes, filesystem artifacts, and config discovery.
- The repo focuses on Chrome DevTools Protocol abuse and browser-session compromise rather than generic malware signatures.
- It is meant to run both locally and in CI, including GitHub Actions, as a fast host-level security check.
