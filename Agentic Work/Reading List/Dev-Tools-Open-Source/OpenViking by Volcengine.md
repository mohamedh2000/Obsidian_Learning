# OpenViking - Open-Source Context Database for AI Agents

> An open-source context database that unifies management of memories, resources, and skills for AI agents through a filesystem-based paradigm.

## Key Points

- Filesystem Management Paradigm for unified context organization across memories, resources, and skills
- Tiered Context Loading (L0/L1/L2 structure) to reduce token consumption by loading only what the agent needs
- Directory Recursive Retrieval combining semantic search with filesystem methods for precise context delivery
- Visualized Retrieval Trajectory for observable, debuggable context flows
- Automatic Session Management that extracts and compresses long-term memory
- Built with Python (v3.10+), Rust, C++, and Go (v1.22+); supports multiple VLM providers (Volcengine, OpenAI, LiteLLM) and embedding models
