# Siftly - AI-Powered Twitter/X Bookmark Manager

> Siftly turns Twitter/X bookmarks into a local searchable knowledge base with AI categorization, visualization, and export tools.

## Key Points

- The project is explicitly local-first: bookmark data lives on the user's machine rather than in a hosted SaaS workflow.
- Its README describes a four-stage AI pipeline for extracting entities, vision signals, semantic tags, and categories from saved posts.
- The output layer includes search, mind-map style visualization, and structured export options such as CSV and JSON.
