# RLM CLI - CLI for Recursive Language Models

> Enables language models to process large contexts by writing Python code to iteratively slice, query, and aggregate information rather than loading everything into a single call.

## Key Points

- Interactive terminal session with persistent context loading for files, directories, glob patterns, and URLs
- Real-time visualization of the RLM loop (code generation, output, sub-queries)
- Model and provider switching on-the-fly across Anthropic, OpenAI, Google (Gemini), and OpenRouter
- Trajectory saving and browsing functionality for reproducibility
- Single-shot CLI mode for scripting and benchmarking against standard long-context datasets (Oolong Synth, LongBench)
- Built with TypeScript (94.5%) and Python (4.7%); requires Node.js >= 20 and Python 3
