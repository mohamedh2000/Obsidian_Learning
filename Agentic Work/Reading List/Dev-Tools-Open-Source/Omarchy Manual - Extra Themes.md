## Key Points

- Install themes by copying the GitHub URL and selecting "Install > Style > Theme" via the Omarchy menu (Super + Alt + Space)
- Remove themes using "Remove > Style > Theme" from the same menu
- Over 150 theme options available, ranging from dark themes (Dracula, Eldritch, Catppuccin) to light themes (Solarized Light, Snow) to retro-styled themes (NES, RetroPC)
- Each theme includes a preview image and a direct link to its GitHub repository
- Omarchy is a customizable Linux desktop environment/framework with community-maintained visual customization options
