# OpenAI CUA Sample App

> OpenAI's sample app demonstrates how to run Computer Using Agent workflows through the API across multiple browser-based environments.

## Key Points

- The repo combines a Next.js operator console with a Fastify runner that manages browser sessions, workspaces, events, and replay artifacts.
- It shows two execution styles against the same scenarios: direct computer-use actions in `native` mode and scripted browser control in `code` mode.
- Shared packages handle the responses loop, scenario manifests, verification, and replay contracts so teams can extend the sample with additional labs.
