# visual-explainer

> visual-explainer is a skill/repo that turns dense terminal output into styled HTML pages or slide decks for diagrams, diff reviews, plan audits, and project recaps.

## Key Points

- Instead of ASCII diagrams and terminal tables, it renders self-contained HTML with typography, theming, Mermaid support, and interactive layout.
- The repo ships focused commands for diagram generation, diff review, plan review, project recap, fact-checking, and optional sharing via Vercel.
- Its structure includes templates, reference docs, and scripts so the skill can pick the right visual format for flowcharts, tables, dashboards, or slide decks.
