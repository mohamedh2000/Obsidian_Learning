## Key Points

- OpenViking treats agent context like a file system with unified `viking://` protocol for memories, resources, and skills
- Tiered loading: L0 (one-sentence abstract), L1 (~2k token overview), L2 (full details on demand)
- Directory-level retrieval with recursive refinement replaces flat vector search
- Self-evolution: automatically extracts learnings and updates agent memory after each session
- 9K stars, Apache 2.0 license, built by ByteDance Viking team
