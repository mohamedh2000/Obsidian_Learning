# Excalidraw MCP App

> Excalidraw MCP App exposes a streamable diagramming server that lets AI clients create and edit hand-drawn diagrams with live viewport control.

## Key Points

- The project is an MCP App server that supports interactive Excalidraw editing, smooth camera movement, and fullscreen diagram workflows.
- It can be consumed remotely via `mcp.excalidraw.com` or installed locally from source or as a packaged Claude Desktop extension.
- The repo also documents self-hosting and Vercel deployment, which makes it useful both as a tool and as a reference for building MCP Apps.
