## Key Points

- The project extends pi with `init_experiment`, `run_experiment`, and `log_experiment` tools plus a live dashboard.
- It persists runs in `autoresearch.jsonl` and keeps a resumable `autoresearch.md` session document so fresh agents can continue the loop.
- The README positions it as domain-agnostic infrastructure for any metric-driven optimization target, from test speed to model training.
