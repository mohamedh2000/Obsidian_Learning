# Paperclip AI - Zero-Human Company Orchestration

> Paperclip orchestrates zero-human companies by giving teams of AI agents a shared dashboard for goals, budgets, governance, and cost tracking.

## Key Points

- The repository describes Paperclip as a Node.js server and React UI for coordinating multiple agents like a managed company rather than a single coding assistant.
- Its core framing is organizational control: org charts, budgets, governance, goal alignment, task management, and auditability.
- The project positions itself above pull-request level work by focusing on business goals and operational oversight for agent teams.
