# Open Source Projects.dev Roundup: A2UI, OpenRAG, and OpenViking

> Saved roundup of three OpenSourceProjects.dev posts covering AI UI generation, local RAG infrastructure, and hierarchical context delivery for agents.

## Key Points

- A2UI is summarized here as a Google-backed tool that turns mockups into responsive, interactive web components.
- OpenRAG is the local-first retrieval stack in the set, bundling ingestion, embeddings, vector storage, and model interaction for private RAG workflows.
- OpenViking is the agent-context project in the group, centered on hierarchical knowledge delivery so models can start with summaries and drill deeper only when needed.

1. **A2UI (Google)** — AI tool that converts design mockups into functional, responsive web components with built-in interactivity and accessibility
2. **OpenRAG** — Build and deploy RAG apps entirely locally. Bundles document ingestion, embedding, vector storage, and LLM interaction in a privacy-focused environment
3. **OpenViking** — Hierarchical context delivery system for AI agents. Organizes knowledge into trees so agents fetch high-level summaries first and drill down only when needed
