# Claude Autoresearch

> Udit Goenka's `autoresearch` repo turns Claude Code into a goal-driven improvement loop that makes one change at a time, verifies it mechanically, and keeps or discards the result.

## Key Points

- The project generalizes Karpathy's autoresearch pattern beyond ML training into code, security, documentation, and other measurable loops.
- It ships as a Claude Code plugin with multiple subcommands such as `plan`, `security`, `debug`, `fix`, and `learn`, all built around mechanical verification and rollback.
