# Yazi - Blazing Fast Terminal File Manager

> Yazi is a Rust terminal file manager built around async I/O, responsive task handling, and a customizable TUI workflow.

## Key Points

- The repo describes Yazi as a cross-platform terminal file manager that uses non-blocking async I/O for speed.
- It highlights real-time task progress, task cancellation, and multi-threaded CPU work as major design points.
- The project is aimed at terminal-heavy productivity workflows across macOS, Linux, Windows, and related tooling ecosystems.
